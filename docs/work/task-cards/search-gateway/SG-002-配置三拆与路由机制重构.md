# SG-002 · 配置三拆与路由机制重构（回溯任务卡）

> ⚠️ 本卡为**回溯补记**：实施工作确已完成，但当时未定义验收标准、未执行正式验收。验收状态 = **待复核**。

## 目标
落实 ADR-002：摒弃旧多渠道智能轮动，改为「默认单渠道单模型 + 显式备用链」，并将配置按职责三拆。

## 实施内容（已完成）
- 新增 `model_catalog.json`（产品目录 / alias / 展示）
- 新增 `model_routes.json`（primary / backup / fallback / fallback_policy）
- 新增 `channel_registry.json`（渠道状态 / credential 引用 / quota / health）
- 新增 `catalog_routes.py`（三拆加载 / 解析 / 路由逻辑）
- 移除默认智能轮动依赖、fallback 改为显式配置（`fallback_policy.enabled=false` 默认）

## 验收标准（回溯补记，待复核）
- [ ] 产品目录不依赖 credential
- [ ] route 可以直接看到 primary / backup / fallback
- [ ] 新渠道不会自动进入流量
- [ ] 默认请求只走指定 primary
- [ ] 备用链行为可配置、可追踪
- [ ] catalog_routes 已接入实际请求转发（/api/gateway-catalog 暴露汇总）
