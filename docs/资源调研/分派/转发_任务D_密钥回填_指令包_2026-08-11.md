## 0. 总则

### 0.1 目标
调度器 `scheduler/credential_map.json` 引用了 5 个 `credential_id`（deepseek-main / siliconflow-main / zhipu-main / openrouter-main / huggingface-main）。
本任务把对应平台的**真实 API key 值**填入本地 `credentials.json`，让 M3 真实上游转发可用。
当前 `credentials.json` 只有 `siliconflow-main`/`deepseek-main` 两个**空 key 占位**，需按 §3 逐平台回填并补上其余 3 个键。

### 0.2 凭证纪律（最高优先，违反即作废）
- 凭证值**只允许写入一处**：`D:\项目\ai-resource-hub\scheduler\credentials.json`（本地受信平面，gitignored）
- 凭证值**绝不**出现在：聊天 / 汇报 / commit / 飞书 / 日志 / 仓库任何文件 / 其他本地文件
- 汇报与验证只写「key 是否已填入」；确需出示证据时脱敏为前 4 + 后 4 字符（如 `sk-ab12...wxyz`）
- **不创建/删除 API Key；不充值；不绑卡；不开后付费；不订阅套餐；不领取需同意「付费回退机制」的权益；不输入/模拟验证码**
- 页面出现**登录墙 / 验证码 / 安全校验**（如 HuggingFace security-checkup）→ 立即停下，该平台标「需人工」，**不尝试绕过**
- 值在提取过程中会经过你的上下文——这不可避免；纪律是**不落盘、不落库、不进汇报**，最终只在 credentials.json 一处
- 推送前自查：`git -C D:\项目\ai-resource-hub status` 确认 `scheduler/credentials.json` 未被追踪；`git diff` 搜索 `sk-`、`Bearer`、`key`、`token=` 等模式

## 2. 提取与写入方法（关键）

### 2.1 提取
```bash
opencli browser <s> open <url>
opencli browser <s> state                      # 看 key 是否在列表/输入框/文本
```
- key 值常见位置：`<input value="sk-...">`、页面文本含 `sk-` 前缀、或点击「复制」按钮后读剪贴板。
- eval JS 示例（**PowerShell 外层双引号、JS 内部全单引号**）：
  ```bash
  opencli browser <s> eval "Array.from(document.querySelectorAll('input')).map(i=>i.value).filter(v=>v.startsWith('sk-'))"
  opencli browser <s> eval "document.body.innerText.match(/sk-[A-Za-z0-9._-]+/g)"
  ```
- 掩码（只显示 `sk-****` 或 `…xxxx`）且页面无复制全值能力 → **不得新建 key**，标「需人工」。

### 2.2 写入（唯一允许落 key 值的位置）
写临时 Python 脚本 `_fill_key.py`，**脚本内不 print key 值**，用后删除、不入仓库：
```python
import json
p = r"D:\项目\ai-resource-hub\scheduler\credentials.json"
d = json.load(open(p, encoding="utf-8"))
d["<credential_id>"] = {"type": "API_KEY", "key": "<KEY_VALUE>"}
json.dump(d, open(p, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
print("written:", "<credential_id>")   # 只打印键名，不打印值
```

### 2.3 校验（不打印值，只打印状态）
```bash
cd D:\项目\ai-resource-hub\scheduler
python -c "import json;d=json.load(open('credentials.json',encoding='utf-8'));print({k:('FILLED' if v.get('key') else 'EMPTY') for k,v in d.items()})"
```
