### 0.5 防卡死边界（核心，替换 v1 隐含逻辑）

借用方案书 Open CLI 状态机语言：`PENDING → LEASED → RUNNING → SUCCEEDED | FAILED | NEEDS_HUMAN`

| 场景 | 停止信号 | 处理 |
|------|---------|------|
| Google OAuth | 出现「需手机验证/二次验证/短信验证码」字样 | 立即 `NEEDS_HUMAN`，**不得模拟输入验证码** |
| Onboarding 问卷（公司名/用途） | — | 用合理占位值（如 "Personal / Research"）尝试提交 **1 次**；仍卡住 → 立即停止记待办 |
| 绑卡要求 | 出现「需要支付方式才能激活」字样，哪怕声称不扣费 | 一律停止，记入待办，**不得输入任何支付信息** |
| 国内手机/微信登录墙 | 确认登录方式后 | 不点击任何登录选项，直接记录，进入下一平台，不等待/不重试 |
| 单平台总耗时 | 国内组 3 分钟 / 海外 OAuth 组 5 分钟 | 超时立即标注「未探测，时间超限」，跳下一个 |

#### 统一状态值（GPT Extended 核实，v2 采用）

每个平台记录以状态值开头（标题 `## 平台 N · 平台名 · <STATUS>`）：
- `AVAILABLE_VERIFIED`：已登录，权益及调用规格已核实
- `AVAILABLE_DOC_ONLY`：官方确认存在资源，但本账号权益未登录核实
- `NO_FREE_QUOTA`：已确认当前账号没有免费额度
- `RETIRED`：产品/API 已退役
- `NEEDS_HUMAN`：验证码/扫码/实名/密码/人工表单阻塞
- `UNKNOWN`：官方资料与控制台均无法确认，**禁止自行猜测**

#### 禁止自动执行（GPT Extended 强调）

- 不创建/删除 API Key；不充值；不绑卡；不开后付费；不订阅套餐；不修改账单设置
- 不领取需同意"付费回退机制"的权益
- 纯技术故障（网络错误/页面加载失败）可重试，但**总 attempt ≤ 3**，达上限转 NEEDS_HUMAN
- 404/入口迁移：最多"旧入口 → 官网导航 → 官方文档搜索"三步，找到官方退役/迁移声明即停，不继续猜 URL

3. **验证**：哪些平台已登录、哪些待永涛登录
4. **已知偏差**：没跑通的平台、猜测、待确认点

### 逐平台动作清单

> ⚠️ 以下动作含 GPT Extended 问诊核实到的 2026-08 最新政策（详见 `docs/ai-advice/两大任务问诊回复_GPT_Extended_2026-08-11.md`）。

- **A1 GitHub Models（退役确认）**：打开 `github.com/marketplace/models` 记录最终 URL/状态 → 打开 GitHub 官方 Models 文档找 "retired / July 30 2026 / inference API 已关闭" 等字段 → **确认退役声明后直接填写 `service_status=RETIRED`、`api_available=false`，不要继续找"新入口"**（官方明确 Models 与 Copilot 是两个服务）。若账号已登录可顺手看 Copilot entitlement，但只新增一条"候选资源：GitHub Copilot"记录，**不得把 Copilot 额度写成 GitHub Models 额度**。验收：看到官方退役声明即算完成。
- **A2 Google Colab**：打开首页确认账号头像 = 已登录 → 新建空白笔记本 → 「Runtime → Change runtime type」记录**当前账户实际**出现的硬件选项（不预设 T4）→ 若免费账户可选 GPU：连接 runtime、仅执行一个最小探针（`nvidia-smi`）记录实际 GPU 型号后**立即断开**；若提示 usage limit/需购买 compute units 原样记录 → 看账户是否显示 Colab 订阅/Compute Units。**不写"免费 T4=固定权益"**（Google 官方明确动态变化）。`api_available=false/N/A`，资源类型记"交互式计算/GPU"不是模型 API。
- **A3 Together.ai**：Google 登录（遇 onboarding 按 0.5 处理）→ **先进 Billing/Credits 而非模型页**：记录 credit balance、有无 promotional/historical credits、是否显示充值要求、有无过期时间。官方当前**无免费 trial，需至少 $5 credits**：余额 0 且要求购买 → 直接 `NO_FREE_QUOTA`，禁止充值 → API Keys 只记 `key_exists` 数量，**不创建新 key** → 记录 Base URL `https://api.together.ai/v1`、OpenAI compatibility、当前 model IDs → Rate Limits 记录**动态值**（不写死 RPM/TPM）。历史 free credits 记现有资产；无则归"付费候选"。
- **A4 Mistral**：打开 `console.mistral.ai` → 登录（普通 Google OAuth 可自动完成）→ Admin/Subscription 记录当前 plan（是否 Free mode、pay-as-you-go 是否启用）→ Usage/Limits 记录 included monthly usage / remaining / reset 周期 / RPM/TPM（**以账户 Limits 页实际显示为准，不预填固定 token 数**）→ API Keys 只记 key_exists → Base `https://api.mistral.ai/v1`、auth Bearer、models 从当前页面可见 ID 记录。出现需绑卡才开 pay-as-you-go → **不开**，Free mode 能否继续单独记录；free allowance 耗尽记录下一 reset 时间，不简单写"无免费额度"。

## 风险（每条一句话）

1. 两个 Agent 并发写同一份验证记录文件，若没按 0.8 分段会互相覆盖——已用「分段 + 主 Agent 合并」处理。
2. Google OAuth 遇未预期 onboarding/二次验证时可能卡住——0.5 节边界可缓解但不能完全杜绝。
3. 免费额度政策随时变，调研当天数字几天后可能过期——靠「验证时间戳」配合后续复核周期。
4. 部分额度需「实际发起一次真实调用」才能验证（如 Colab 是否真给 GPU）——严格守「只看选项文案，不实际连接消耗」。
5. 官网公开定价页与控制台实际额度可能不一致——双源标注来源，不能只信一处。
6. Mistral/Together 免费层若已改「强制绑卡才可用」，按旧认知硬闯有被要求填支付信息、误触发扣费的风险——见到绑卡要求立即停。
7. 新增的 endpoint/模型名/限流字段，页面未说明时 Agent 有编造倾向——prompt 反复强调「未说明就写未说明」。
