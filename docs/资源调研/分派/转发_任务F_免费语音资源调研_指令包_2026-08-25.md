## 0. 总则

### 0.1 目标
调研国内外免费语音 AI 资源，三件事：
1. **发现**：各平台免费 TTS / ASR / 语音克隆 / 实时语音能力及免费额度
2. **核实**：免费规则、每日免费额度、有效期、领取方式是否准确
3. **输出**：结构化调研结果（§4 格式），可直接回填飞书多维表格「多模态生成资源库」

### 0.2 调研边界（最高优先，违反即作废）
- **不充值、不付费、不绑卡、不订阅套餐、不开启后付费**
- 只调研**免费额度 / 免费档**；付费内容仅作备注
- **严禁编造**：所有额度、规则、有效期必须来自官方页面 / 官方文档 / 实测；无法确认的标注「未确认」
- 每条信息标注**来源**（官网URL / 官方文档 / 实测 / 第三方）

### 0.3 调研分类
| 类别 | 说明 | 示例 |

地区：**大陆** / **海外**

## 2. 每条资源的调研字段

与飞书「多模态生成资源库」表字段一致：

| 字段 | 类型 | 说明 |
|------|------|------|
| 工具名称 | text | 平台/工具名称 |
| 类别 | 多选 | TTS语音合成 / ASR语音识别 / 语音克隆 / 实时语音 |
| 地区 | 单选 | 大陆 / 海外 |
| 所属公司 | text | 运营公司 |
| 能力 | text | 支持的能力（如「TTS、ASR、实时语音」） |
| 官网链接 | url | 官方入口 |
| 免费规则 | text | 免费政策描述（含口径来源） |
| 每日免费额度 | text | 具体数值（如「每日10万字符」） |
| 有效期 | text | 额度有效期 / 清零规则 |
| 领取方式 | text | 自动到账 / 手动领取 / 实名认证 |
| 备注 | text | 实测结果、注意事项、口径差异 |

> 可选测试字段（执行 AI 有账号且能实测时填写，否则留空）：登录成功 / 额度到账 / 扣减正确 / 生成成功 / 总体结论（值：通过 / 失败 / 未测）

## 3. 调研步骤

### 3.1 官方信息核实（每个平台必做）
1. 打开官网 / 官方文档 / 定价页
2. 记录：免费规则、每日额度、有效期、领取方式
3. 记录来源 URL 作为证据

### 3.2 第三方交叉验证
- 搜索第三方评测 / 教程 / 社区讨论，交叉验证免费规则
- 官方与第三方不一致时，两者都记录并标注口径

### 3.3 免费额度实测（可选，有账号时）
- 登录账号，确认额度是否到账
- 实际调用一次（TTS生成一段语音 / ASR转写一段音频），确认扣减是否正确
- 记录实测结果（成功/失败、扣减数值、质量）

### 3.4 新资源发现
- 调研过程中发现的、表中未列出的免费语音资源，按 §2 字段完整填写

## 4. 输出格式

输出一个 Markdown 文件，包含三部分：

### 4.1 调研结果表
```markdown
| 工具名称 | 类别 | 地区 | 所属公司 | 能力 | 免费规则 | 每日免费额度 | 有效期 | 领取方式 | 备注 | 来源 | 核实状态 |
```
- `核实状态`：准确 / 需更新 / 无法确认（说明原因）
- `来源`：官网URL / 官方文档 / 实测 / 第三方

### 4.2 新增资源表
新发现的免费语音资源，同格式完整填写。

### 4.3 更新建议汇总
- 哪些平台值得优先实测
- 哪些信息无法确认，需要人工核实

## 5. 汇报要求（四段式）

1. **调研概况**：调研了多少个平台，其中准确 / 需更新 / 无法确认各多少
2. **新增资源**：新增了多少个资源，分别是什么类别
3. **关键发现**：哪些平台免费规则有变化、哪些值得优先实测
4. **不确定项**：哪些信息无法确认、为什么、需要什么帮助

> 汇报追加到文件末尾，无需发消息、无需等确认。
