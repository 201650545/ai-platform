## 0. 总则

### 0.1 目标
用户当前紧缺可用的免费 API 渠道，需要做一次系统性调研，三件事：
1. **核实**：§1 已知线索清单中每个平台/活动的免费规则、额度、有效期、领取方式是否准确、是否仍有效（很多是限时活动，可能已过期）
2. **补充**：发现清单中未收录的免费 API 平台/活动（新增条目，重点找**新上线、限时、大额度**的）
3. **输出**：结构化调研结果（§4 格式），可直接用于接入 API 网关 / Cherry Studio

### 0.2 调研边界（最高优先，违反即作废）
- **不充值、不付费、不绑卡、不订阅套餐、不开启后付费**
- 只调研**免费额度 / 免费档 / 限时活动**；付费内容仅作备注
- **严禁编造**：所有额度、规则、有效期必须来自官方页面 / 官方文档 / 实测；无法确认的标注「未确认」，不得猜测
- 每条信息标注**来源**（官网URL / 官方文档 / 实测 / 第三方），第三方信息需标注「第三方口径」
- **重点标注截止时间**：限时活动必须写清楚「截止日期」，并标注「今天（2026-08-26）是否仍有效」

## 3. 调研步骤

### 3.1 官方信息核实（每个平台必做）
1. 打开官网 / 官方文档 / 定价页
2. 记录：免费规则、额度、有效期、截止时间、领取方式
3. 记录来源 URL 作为证据

### 3.2 第三方交叉验证
- 搜索第三方评测 / 教程 / 社区讨论（什么值得买、CSDN、知乎、GitHub），交叉验证免费规则
- 官方与第三方不一致时，两者都记录并标注口径
- **重点找「限时活动」的截止日期**，判断今天是否仍有效

### 3.3 免费额度实测（可选，有账号时）
- 登录账号，确认额度是否到账
- 实际调用一次 API，确认是否可用
- 记录实测结果（成功/失败、响应内容）

### 3.4 新资源发现（重点）
- 调研过程中发现的、清单中未收录的免费 API 平台/活动
- **优先找**：新上线平台、限时大额度活动、免绑卡免预充值的平台、学生/新用户专属福利
- 按 §2 字段完整填写，单独列入「新增资源表」

## 4. 输出格式

输出一个 Markdown 文件，包含四部分：

### 4.1 核实结果表
对 §1 的 29 条线索逐条核实，在末尾加两列：
```markdown
| 平台名称 | 类别 | 地区 | 所属公司 | 能力 | 免费规则 | 免费额度 | 有效期 | 截止时间 | 领取方式 | 备注 | 来源 | 核实状态 |
```
- `核实状态`：仍有效 / 已过期 / 需更新（说明变化点）/ 无法确认（说明原因）
- `来源`：官网URL / 官方文档 / 实测 / 第三方

### 4.2 新增资源表
新发现的免费 API 平台/活动，同格式完整填写。

### 4.3 优先接入建议
- 按「值得优先接入」排序（免费额度大、稳定、OpenAI兼容、免绑卡）
- 每个平台一句话说明推荐理由
- 标注哪些需要尽快领取（临近截止的限时活动）

### 4.4 更新建议汇总
- 哪些平台免费政策有重大变化（新增/取消免费档、活动到期）
- 哪些信息无法确认，需要人工核实
