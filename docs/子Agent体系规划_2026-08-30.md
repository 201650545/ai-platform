# 子 Agent 体系规划（2026-08-30）

> 目的：Claude Code 作为调度中心（唯一窗口），把重复性/简单任务委派给子 Agent 执行，省 Claude token、提效率。
> 子 Agent 只有两种形态：**A. API 网关免费模型** 与 **B. Agent 程序（opencli 连接）**。本文定各自模型选择与使用规则。
> 原则：Claude 只做调度、审核、关键决策；一切可委派的都委派。

---

## 一、两种形态

| 形态 | 载体 | 特点 | 适合 |
|------|------|------|------|
| **A. API 子 Agent** | :3100 网关免费模型（`subagent.py` 委派） | 快、省、无界面、可批量并行、无状态 | 简单/重复/确定性任务 |
| **B. 程序子 Agent** | opencli 连接桌面 AI（Trae / 豆包 / Qoder） | 强上下文、有 Agent 能力、可操作工程/文件 | 复杂/工程/需工具任务 |

## 二、A 类：API 网关免费模型（subagent.py）

**只配两个模型名**（用户 2026-08-30 拍板，本地要简洁）：

| 模型名 | 实际内容 | 定位 |
|--------|---------|------|
| `deepseek-free` | DeepSeek 全部模型链（网关已排好序） | 默认通用 |
| `fast` | 各渠道免费模型集合 | 补充/兜底 |

**deepseek-free 内部排序规则**（网关 `unified_models.json` 已配）：
1. 免费且速度快的放前面（**魔塔社区免费 125 次/天 DeepSeek-V4-Pro-0813 放最前** → B.AI vision → 商汤 → nvidia → 百炼）
2. 速度慢的放后面
3. **付费垫底**：最后以付费模型垫底（**opencode go 的 DeepSeek V4 flash**）

**测试禁忌（强制）**：**不能乱测！** 部分平台已充值，乱测会打到高级/付费模型浪费钱。测试只走 `deepseek-free`/`fast` 两个编排名，绝不直呼其他模型名。

用法：`python D:\项目\services\subagent.py "任务" [--model fast] [--file 路径] [--sys 提示]`

**规则**：
- 默认 `deepseek-free`；其失败/空回复→换 `fast`→再不行 Claude 接手，不无限重试
- 长上下文任务用 `--file` 传文件，不塞进聊天
- 去掉了 glm-5.2（基本用不了）、千问3.8-flash（额度不明）等 A 类杂模型

## 三、B 类：Agent 程序（opencli）

程序选择（用户 2026-08-30 拍板）：

| 程序 | 模型/配置（锁定） | 适合 |
|------|----------------|------|
| **Trae Work** | **DeepSeek V4 flash 正式版**（不可换） | 通用工程/写代码/文档/分析——**B 类默认** |
| **豆包** | **工作模式（已开）+ 思考调到低** | 信息搜索/口语/多模态/日常问答 |
| **Qoder** | **千问 3.8 flash** | IDE 工程任务（Qoder 的 IDE 场景） |
| Antigravity | 故障中（Google RemoteControl 代理） | 待解决后再纳入 |

用法：
- Trae：`opencli trae-solo open-task --project X` + `opencli trae-solo send "任务"`
- 豆包：`OPENCLI_CDP_TARGET="doubao://doubao-chat/chat" opencli doubao-app ask "任务"`
- Qoder：`opencli qoder ask "任务"`（发送已通，回复提取待优化）

**规则**：
- Trae 是 B 类主力（写码/工程强）；模型锁 DeepSeek V4 Flash 正式版，不切
- 豆包用于信息类（搜索/口语/多模态），工作模式开 + 思考低
- 长任务用 `open-task` 开独立任务，避免污染现有会话
- 测试判断不用 B 类（省 B 类额度），用 A 类 `deepseek-free`

## 四、任务分配决策表（Claude 调度判断）

| 任务类型 | 委派给 | 理由 |
|---------|-------|------|
| 简单问答/翻译/总结/格式化/批量文案 | A 类 deepseek-free | 最快最省 |
| 代码片段/JSON/结构化输出 | A 类 qwen3.8-flash | 代码准 |
| 写代码/改代码/工程操作/文档生成 | B 类 Trae | 需工具/上下文 |
| 信息搜索/汇总/多模态 | B 类豆包 或 :3000 搜索网关 | 豆包搜索强 |
| IDE 内工程任务 | B 类 Qoder | IDE 场景 |
| 测试判断/验证 | A 类免费模型 | 不花 B 类额度 |
| 架构设计/关键决策/多 Agent 协调 | **Claude 自己做** | 调度核心不委派 |

## 五、成本与额度规则

1. **A 类全免费**（:3100 免费模型），不花 Claude token、不花付费模型
2. **B 类用程序自带免费额度**（Trae/豆包/Qoder 都免费）
3. **Claude 只做**：接用户任务 → 判断委派 → 审核子 Agent 产出 → 汇报/回写
4. **降级链**：A 类模型失败 → 换同 A 类其他模型 → 再失败转 B 类 Trae → 仍不行 Claude 接手（或上报）
5. 每日 B 类程序调用注意额度（豆包/Qoder 免费但有限）；A 类无限

## 六、委派流程

```
用户 → Claude（调度中心）
  ├─ 简单/重复 → subagent.py 委派 A 类免费模型 → 结果回 Claude 审核 → 汇报
  ├─ 工程/写码 → opencli Trae/豆包/Qoder 委派 B 类 → 结果回 Claude 审核 → 汇报
  ├─ 搜索/资讯 → :3000 搜索网关 / 豆包
  └─ 架构/决策 → Claude 自己做
产出 → 回写飞书/GitHub → sync_all.py 三端同步
```
