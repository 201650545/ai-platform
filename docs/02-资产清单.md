# 02 · 资产清单（凭据存放位置与槽位名）

> **红线声明**：本清单只登记凭据的「存放位置」与「槽位名（env 变量名 / GitHub Action secret 槽位名）」，**值一律回显禁**。key 值 / token 值 / prefix / 前缀 / 后缀**不入本清单、不入仓、不进任何公开输出**。敏感数据面（`history.json`、飞书 `conversations.question/answer`）**不计入本清单**。

关联：[[docs/00-项目总览.md]] · [[docs/03-规格与规范.md]]

## 一、外部 API 凭据（存放位置 + 槽位名）

| 用途 | 槽位名（env 变量 或 GitHub secret） | 存放位置 | 备注 |
| --- | --- | --- | --- |
| 网关某外部渠道 API Key | `SECRET_<渠道>`（例名，以实际配置为准） | 网关 `config/` 本地配置 | 值不登记 |
| 外部模型 API Key | `SECRET_<模型>`（例名，以实际配置为准） | 网关 `config/` 本地配置 | 值不登记 |
| CI 部署/发布集成凭据 | GitHub Action secret（槽位名以实际配置为准） | GitHub Actions secrets | 值不登记 |
| Pages 外部资源/构建集成凭据 | GitHub Action secret（槽位名以实际配置为准） | GitHub Actions secrets | 值不登记 |
| （预留）生产环境运行凭据 | 对应 env 变量名（以实际配置为准） | 目标运行环境 | 值不登记 |

> 说明：凡当前拿不到精确 env 变量名的条目，均以「例名 / 以实际配置为准」标注，**不臆造精确变量名**，留待接入时校正。

## 二、内部运行时凭据

| 用途 | 槽位名 | 存放位置 | 备注 |
| --- | --- | --- | --- |
| 中央平台认证 token | 运行时生成 | 本地 `config/auth.json` | 值不登记 |
