# AI 基础设施 — 端口登记

> 本表为**端口 → 服务的权威索引**。端口绑定以 `config/gateways.json` 声明为准，
> 是否监听以 `gateway_runtime.json` 为准。修改端口先改 `gateways.json`，再重新探测。

## 端口 → 服务

| 端口 | 宿主 | 服务 | 方向 | 说明 |

| 8000 | 127.0.0.1 | central | 入口 | 中央平台 / API / 管理面板 |
| 8791 | 127.0.0.1 | orchestrator | 入口 | 组件编排器（serve-only） |
| 3000 | 127.0.0.1 | search_gateway | 入口 | 搜索网关（含历史记录） |
| 3100 | 127.0.0.1 | search_gateway | 入口 | OpenAI 兼容 API 转发网关 |
| （已释放） | 127.0.0.1 | —(孤儿) | — | 8898 / 8899 已清理，勿再占用 |
