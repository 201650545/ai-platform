# AI 基础设施 — 网关/服务全景总览

> 跨服务的**全局事实索引**。本页只描述「现在是什么、谁在哪、如何探测」；
> 设计原因、建设历史见各服务文档与 ADR。
> 运行身份、canonical path、端口与 desired state **以 `config/gateways.json` 为准**；
> PID、alive、health、drift **以 `gateway_runtime.json` 为准**。

## 原则（铁律）

1. **配置态与运行态分离**：`gateways.json` 只存声明（期望状态/身份/路径），绝不写 `online/pid/health`。
2. **运行态由探测产生**：`inspect_gateways.ps1` 只读探测，生成 `gateway_runtime.json`（全量）+ `gateway_drift.json`（异常投影），**禁止手改**。
3. **代码位置是真实存在源**：Obsidian 只解释与索引，不反向充当运行事实源。
4. **canonical path 唯一**：同一功能只认一份代码；其余是 archive/reference 副本。
