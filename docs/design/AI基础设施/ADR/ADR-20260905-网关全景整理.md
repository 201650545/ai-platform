# ADR-20260905 · 网关全景整理：声明/运行分离 + canonical 核算法

## 背景

多个网关/服务（central、orchestrator、search_gateway、ds_v4_cli）散落于
`D:\项目\services\*`、`D:\项目\ai-hub\*`、`D:\游戏\ds_v4_cli`，config/gateways.json 停留在 v1
（混入 `status: online` 等运行态），且存在孤儿进程（8898/8899）未被识别。

## 决策

1. **配置态与运行态分离**：`gateways.json` 升级 schema v2，只存声明；运行态由
   `inspect_gateways.ps1` 探测写入 `gateway_runtime.json` / `gateway_drift.json`（禁止手改）。
2. **canonical 核算法**：以「①运行入口 ②启动/config/脚本 ③Git/维护信号」多数票定唯一路径。
3. **清理孤儿**：8898（指向已删目录）、8899（无目录裸服务）确认身份后停止。
4. **Obsidian 只解释不反向**：新增 `AI基础设施/` 目录做跨服务索引与服务页，不保存 PID/online。

## 结果（canonical 判定）

| 服务 | canonical | 说明 |
|---|---|---|
| central | `D:\项目\services\central` | 运行中(PID→server.py)，被 D:\项目 git 跟踪 |
| orchestrator | `D:\项目\services\orchestrator` | 运行中(PID→canvas_server.py --serve-only) |
| search_gateway | `D:\项目\ai-hub\search_gateway\services` | 唯一；计划任务/watchdog 指向此处 |
| ds_v4_cli | `D:\游戏\ds_v4_cli` | legacy，不在 ai-hub |

> ai-hub 子仓库内 `00_中央平台/`、`06_组件编排器/` 为参考副本/历史位，非运行 canonical。

## 附注

`runtime.yaml` + `runtime.cli` 属另一套 management 工具（Desired State + state.json）；其
search_gateway cwd 为历史约定，已在文件头注释说明 canonical 迁移事实，不强行改代码。

**MCP 封装决策**：将 search_gateway 的 AI 搜索能力以**标准 MCP server** 暴露（而非自定义工具），
原因：MCP 是当前 Agent 工具互操作通用标准，TRAE / Claude Code / DeepSeek harness / opencode 均可直接接入；
同时对不支持 MCP 的 harness 保留 OpenAI 兼容 base_url（`http://127.0.0.1:3000/v1`，model=`yuanbao-search`）。
