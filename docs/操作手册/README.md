# AI 操作手册（docs/操作手册/）

> 用途：**切换对话/新执行 Agent 后，操作方法如何延续**——这是本目录存在的唯一理由。
> 对话上下文不共享，文件记忆共享，本手册 = 显式的操作方法传承层。
> 存储决策：**GitHub 仓库为主**（公开，任何 AI 可实读）+ 本地天然镜像；不进飞书多维表格（那是结构化配置真源，非 SOP 文本）。

## 新对话/执行 Agent 怎么用

1. **先读 02（OpenCLI）**——所有浏览器动作都靠它，命令结构/引号规则必须知道。
2. **要问 GPT** → 读 01（镜像站），核心是 localStorage 登录 + base64 注入 + stop 判定。
3. **要问 Claude** → 读 03，核心是 `tab new` 不覆盖 + body 文本判定。
4. 完成后：结果落档 `docs/` 对应目录，四段式汇报给郭老师。

## 维护约定

- 界面/账号池/域名**会漂移**（已发生：域名 wendabao-f→wendabao.net、账号 ⑮→⑲），手册**边实测边更新**，执行 Agent 若发现失效路径立即回报修订。
- 凭证值（JWT/token/key）永远只记"怎么读"，不记完整值。
