# 飞书多维表格 · 设计方案

> 版本：v0.3（2026-08-10，GPT-5.6 实读版 + Claude Sonnet 5 第二意见综合定稿）
> 前版：v0.2（6 表初稿）→ v0.3 按两份高级 AI 问诊修正
> 定位：AI 自助资源运营体系的**配置真源**（资源配置的唯一权威来源）
> 状态：定稿 → 在飞书 base 落地 → 对接本地 SQLite（运行时真源）
> 问诊依据：`docs/ai-advice/gpt56_问诊回复_实读版_2026-08-10.md` + `docs/ai-advice/claude_sonnet5_问诊回复_2026-08-10.md`

## 〇、真源分工（不变，强化）

| 平面 | 谁 | 存什么 | 为什么 |
|------|-----|--------|--------|
| **配置真源** | 飞书多维表格 | 能力定义 / 账号 / 凭证引用 / 实例登记 / 人工可视化 | 人类和 AI 认这个为准 |
| **运行时真源** | 本地 SQLite | 实时额度计数 / cooldown / **lease / 幂等 UNIQUE / 状态转换** | 飞书官方不支持并发写，lease 当锁会冲突 |

**关键强化（两份问诊共识）**：
- **lease / UNIQUE(idempotency_key) / 状态转换全部以 SQLite 事务为真源**，飞书表 6 只是审计镜像
- 同步：配置 飞书→SQLite；运行态摘要 SQLite→飞书（周期/事件，**不每次请求都写**）
- 飞书断网时验证结果不丢：`task=SUCCEEDED` + `sync_state=PENDING`，恢复后继续回写

## 一、设计原则（5 条）

1. **AI 可读可执行**：每条能力带 endpoint / models / exec_type / 请求体模板，AI 读表即知「怎么用」
2. **凭证不出表、Secret 不进配置平面**：表里只有凭证 ID；**请求头不存 `{{CREDENTIAL}}` 模板**，改由飞书声明 `auth_scheme + allowed_hosts`，本地受信 adapter 注入 Secret
3. **能力与实例分离**：一个逻辑能力可挂多个实际实例，轮换只换实例、不换模型
4. **单一真源**：每个字段只有一个权威维护点，不两处手填（尤其 routing_group）
5. **状态驱动**：调度器只消费 `status=可用` 的实例

## 九、表间关系

```
账号资产(1) 1 ──< 凭证池(2)      ← account_id
凭证池(2)   1 ──< 资源实例(4)    ← credential_id
资源能力(3) 1 ──< 资源实例(4)    ← capability_id（routing_group 继承能力，不手填）
资源实例(4) 1 ──< 任务日志(6)    ← 关联实例
工具资产(5)    独立
```

- **轮换路径**：表 3 能力（锁模型+质量+routing_group）→ 表 4 该能力下可用实例 → 排序 → 表 2 凭证 ID → 本地取密钥 → 调用（Secret 只发 allowed_hosts）
- 表 6 是审计痕迹，幂等真源在 SQLite

## 十一、与执行层对接点（更新）

- **调度器（本地进程 + base_url 代理 + SQLite WAL）**：读表3+表4 → 错误分类（quota_exhausted→EXHAUSTED / 429→COOLDOWN / 401→CRED_INVALID / model_not_found→CONFIG_INVALID / 5xx→短暂失败可切）→ 同组轮换 → **流式已输出内容后禁切换实例** → 运行时计数写 SQLite → 摘要同步回表4
- **Open CLI（独立 Chrome Profile，任务状态机）**：领 lease → 执行 → 结构化结果 → 同一 SQLite 事务更新 instance+task+outbox → 单写者回飞书；`NEEDS_HUMAN` 阻塞不自动重试；**清理任务**扫描过期 LEASED/RUNNING → PENDING
- **数据桥（Public Read Model）**：白名单 DTO + **额度区间模糊化** + 时间戳 + 敏感字段扫描（GitHub Action）；**不公开**：account_id、credential_id、手机绑定、错误详情、内部路由优先级、精确额度
- **长期监控**：按 next_verify_at 调度验证；模板/凭证变更（config_version）驱动重验
