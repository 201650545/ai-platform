## 一、总原则（来自 Extend 方案核心结论）

1. **间隔由 FSRS 动态算**，不硬编码 1/3/7/15/30 天（保留为冷启动参考轨迹）。
2. **"复习轮次"与"下次复习时间"拆成两个变量**：round 管题型/提示强度，next_review_at 管何时再见。
3. **learning-log = 事实源（append-only）**，vocabulary = 当前状态快照，competency-state = 聚合能力估计。三者不混用。
4. **答错退回 round-1**；连续 2 次正式复习 Again → relearning(R1)；30 天 ≥3 lapse → 困难词干预。
5. **第 6 轮不是毕业** → maintenance，继续 FSRS 长期维护（60/100/200 天级）。
6. **中译英提前到 R3**（receptive→productive 迁移只有部分发生，两个方向都要练）。

## 四、能力状态表（competency-state）联动规则

> 现状：19 字段（含 能力维度/当前等级/间隔天数/稳定度/连续成功次数/连续失败次数/下次复习时间/是否到期/是否稳定掌握）。**字段已够用，本次不新增字段，只明确联动规则。**

### 联动规则（写回顺序：学习日志 → vocabulary → 能力状态）

1. **能力维度**固定 4 维：receptive_vocab / productive_vocab / contextual_usage / lexical_discrimination（可加 spelling_form）。
2. **能力值** = 过去 90 天 weighted Beta：`(1+Σ(w·y)) / (2+Σw)`，w 按题型证据权重（Extend §25）：
   - 英中2选1:0.15 / 英中无提示:1.00 / 中英无提示:1.00 / 语境运用:1.20 / 近义辨析:1.00 / 带提示成功:0.2–0.6
   - **同日任务 × 0.5**（同日成功 ≠ 隔天检索）
3. **当前等级** = 能力值×100（0-100）。
4. **稳定度** = 近 N 次能力值方差或连续成功趋势（沿用现有逻辑）。
5. **间隔天数** = 该能力维度下平均 FSRS 间隔（可保留现有公式字段）。
6. **是否到期** = 下次复习时间 ≤ 当前时间（沿用现有 formula）。
7. **能力表不能反推单词间隔**：单个词什么时候复习仍由该词自己的 D/S/R 决定（Extend §27 边界）。
