### 5. 项目宏大，如何不烂尾

**【分阶段资产策略：先做哪几个境界】**

1.  **先做「前3境」（凝气→筑基→结丹）**：这是动画目前最完整、观众认知度最高、官方素材最多的阶段。王林形象从少年到青年的变化也最明显，适合验证角色一致性管线。

2.  **再做「化神→婴变→问鼎」**：化神是王林气质转折的关键点（白发/冷漠），视觉差异大，能验证风格统一策略。

3.  **后六境用「占位符」**：碎涅以后的王林（星袍、踏天）官方素材少，AI生成难度大，先用前六境资产改色调+高斯模糊+境界文字作为占位，引擎不卡。


**【占位后补的具体做法】**

-   **背景占位**：建立 `assets/placeholder/` 目录，放12张纯色渐变图（CSS `linear-gradient` 导出为JPG），每张标注境界名。引擎的 `asset-manifest.json` 中后六境先指向占位图，完成后替换路径即可。

-   **立绘占位**：用官方王林「通用形象」一张图，通过CSS `filter: hue-rotate()` 和 `brightness()` 临时区分境界，后续替换真实立绘文件。

-   **视频转场占位**：用CSS全屏动画替代——旧境界图 `opacity:1 → 0` + `scale:1 → 1.2` + `filter: brightness(3)`，持续1.5秒，配合白色遮罩闪过。效果足够震撼且零视频成本。


**【资产可插拔设计：引擎不被资产卡住】**

1.  **manifest驱动**：每个境界一个JSON配置，引擎只读取配置，不硬编码路径。

    ```json
    {
      "realm_id": "03_jiedan",
      "assets": {
        "bg": "realms/03/bg.webp",
        "character": "realms/03/wanglin.png",
        "bgm": "audio/03.ogg",
        "transition_video": null
      },
      "fallback_realm": "02_zhuji"
    }
    ```

    当 `transition_video` 为 `null` 时，引擎自动降级为CSS转场。


2.  **角色渲染器抽象层**：

    ```plain
    interface ICharacterRenderer {
      render(state: 'idle'|'thinking'|'casting'|'hit'|'breakthrough'): void;
    }
    ```

    v1实现：`CSSSpriteRenderer`（DOM+CSS动画） v2实现：`Live2DRenderer`（Cubism SDK） v3实现：`ThreeDRenderer`（Three.js） 引擎层通过配置切换，无需改业务代码。


3.  **热更新机制**：开发时用 Vite 等工具本地伺服，资产文件替换后刷新即生效，无需重启引擎。


4.  **资产版本命名**：`wanglin_v1.png`、`bg_03_v2.webp`，保留旧版，新版改manifest指向即可回滚。

## 风险与坑（每条一句话）

-   **角色LoRA训练素材不足15张或角度单一，生成结果不像王林**：优先用IP-Adapter/cref降低门槛。

-   **AI视频目前单次生成仅4-5秒，破境转场需拼接，可能出现画面闪烁跳跃**：用DaVinci做光流补帧或直接用CSS转场保底。

-   **免费音效库风格杂糅（有的偏科幻有的偏武侠）**：统一用Audacity加混响（Reverb）和均衡（EQ削减低频）伪装成同一空间。

-   **浏览器本地文件协议（file://）无法加载视频和字体，预览时必须启本地服务器**：用Vite或Python `http.server` 一键起服务。

-   **12境界×多资产，两周后文件夹必然混乱**：必须严格执行 `01_ningshi_bg_v1.webp` 命名，否则后期替换时找不到文件。

-   **Midjourney等工具的 `--cref` 对国风古装角色一致性弱于二次元**：王林LoRA训练时建议混入少量真人明星脸数据集提升真实感（如有版权风险则仅用动画截图）。

-   **踏天九桥等后期境界缺乏官方视觉参考，AI容易生成西幻风格**：需在提示词中强化 `xianxia, chinese cultivation, taoist` 等文化锚点词。
