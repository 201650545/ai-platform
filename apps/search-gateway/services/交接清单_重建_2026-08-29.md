## 2. 用户遇到的核心问题
- 现象：Fast 模型思考一会儿后突然停住，正文不输出。
- 已定位原因（查 dsh 会话日志，turn 77）：
  1. Fast 模型思考（reasoning）里带了敏感信息（如 API key），触发上游渠道安全过滤。
  2. 渠道返回 `finish_reason=content_filter`。
  3. 网关现有逻辑把 `content_filter` **归一化成 `stop`**（`api_gateway.py` 的 `_normalize_content_filter`，2026-08-29 为消除 Harness 硬错误而加）。
  4. 客户端（dsh Harness）把 `stop` 当正常结束 → 只有思考、没有正文，表现为"想完就停"。
- 关键点：**保留 `_normalize_content_filter` 就必须同时有"content_filter 即渠道失败→自动换下一渠道"的故障转移**，否则静默停止会一直存在。
