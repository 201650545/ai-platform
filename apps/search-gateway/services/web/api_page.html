Truth constraints

Three separate states
  • Member cooldown: 30s，后端当前未直接暴露；UI 仅根据 member_pool 最近 breaker failure ≤30s 标为“inferred cooldown”。
  • Rate limit: 直接来自 /api/rate-limits 的 open / throttled / blocked。
  • Fault domain: 仅在后端显式字段或 route-log 的 proxy_blocked 观测证据存在时表达；无证据时显示“live state not exposed”，不猜测。
  • Member selection: 按 members[] 原顺序，不做额度+延迟动态加权。
  • Backup chain: 只有 fallback_policy.enabled=true 才展示。
