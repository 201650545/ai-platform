# V5.2 方案 —— V4 皮 + V5 骨

> 前提与判决见 `V5-DEVLOG.md` 2026-09-09 条目：V5.1 程序化素颜观感被否决（引擎保留，皮全换）；V4 点名两处硬伤——比例失衡、建筑与山画风硬拼。本文档为 V5.2 设计，走外部评审后实施。

## 一、一句话

把手绘感分层素材装回 V5.1 的引擎上：**山雾地面复用 V4 素材，建筑按山的画风重画，只太阳与月亮（含星）做三维**，昼夜仍是单参数 u。

## 二、结构与层序（z-sandwich）

```
.scene                      position:fixed + 不透明底（mix-blend-mode 隔离教训）
├─ .sky        z0           昼夜渐变画在 .scene 自身，随 u 插值（V4 已验证）
├─ canvas#gl   z1           透明 WebGL：星 / 太阳 / 月亮 / 光晕（只此三维）
├─ .layer.mtn  z2           远山（v4-mid day/night crossfade + flip 镜像层）
├─ .layer.fog  z3           雾（顶部羽化，screen）
├─ .layer.floor z4          地面（v4-floor day/night）
├─ .layer.arch z5           新建筑（新生成 day 素材 + 夜间 CSS 染色 + 窗光层）
├─ .layer.fg   z6           近景剪影（v4-fg）
├─ .grain      z7           颗粒（静态）
└─ HUD         z10          V5.1 的 DOM UI 原样嫁接（问候/时钟/KPI/providers/路由 SVG/七页）
```

- 日月 canvas 放山层之下：月从山脊后升起、太阳落山被脊线吞掉，遮挡天然正确，零额外代码。
- 建筑在雾上、fg 下：底边落在地面释放线，边缘吃一点雾，消除"贴纸感"。

## 三、资产清单

| 项 | 来源 | 说明 |
|---|---|---|
| 远/中/近山、雾、地面、颗粒 | V4 复用（9 张） | 现成且用户认可；只做比例裁切 |
| 建筑主体 | **新生成**（day ×1） | 见提示词约束；夜间用 CSS filter 压暗去饱和 |
| 窗光层 | 新生成或 CSS | 夜间小暖光斑，透明 PNG 或 box-shadow 群 |
| 日/月/星 | **无资产** | 三维球体+光晕 sprite，V5.1 代码改配色移植 |

建筑生成约束（防"写实回潮"）：水墨雾面低饱和、与 V4 山同调；正面微侧 ≤15°，消失点对齐山脊；纯白底出图（复用白底归一化+阈值截断管线）；同批多出几张择优，垫 V4 山图做风格参考。**比例修正**：屏高占比从 V4 的 ~78% 压到 ~50%，整体退远，左 1/3 构图不变。

## 四、引擎接线（改哪里）

- `scene.js` → 重写为"分层合成器"：不再建地形/建筑网格，只保留透明 renderer（alpha:true）画日月星；DOM 层序由 index.html 承担。
- `timeline.js` → STOPS 保留，输出从"three 材质参数"改为"CSS 自定义属性 + 日月星空参数"双通道；UI 墨色 u>0.5 翻转沿用。
- `main.js` → rAF/看门狗/失焦暂停/parallax 全保留；parallax 从相机旋转改为分层位移（far 动 20%、mid 50%、arch/floor 100%，日月 30%）。
- `ui.js` / `i18n.js` → **零改动**。

## 五、验收 Gate

- **GateA 底盘**：白昼静止截图与 V4 并排，画风无断层、建筑不突兀、比例成立。
- **GateB 昼夜**：u 单参数四时刻截图 + 过渡中帧，morph 连续。
- **GateC 三维日月**：月升从山脊后探出的遮挡正确；日光高度联动地面/建筑暖色 tint。
- **GateD 性能**：合成层预算内、fps 达标、1920×1200 验收。工具沿用 CDP 管线。

## 六、风险与对策

1. 建筑生成风格跑偏 → 垫风格参考图 + 同批多张择优，评审时先看资产再写代码。
2. 白底不纯留矩形缝 → 复用 V4 归一化+截断脚本思路，入库前逐张校验。
3. blend 模式在新结构失效 → .scene 始终不透明；改动层序后立即 CDP 截图自检。
4. 层数多掉帧 → 颗粒/远山静态化，动画属性只留 opacity/transform/filter。

## 七、不做的事

- 不做逐页相机移动（沿用降曝光）；不做 3D 路由线；不新增六页真实内容（另案）；3100 线上全程不碰。
