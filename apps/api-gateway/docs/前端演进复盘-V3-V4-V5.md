## V4-实验（2026-09-09 00:20，我）

- **做了什么**：单页总览。13 张 AI 生成分层 PNG（建筑/三层山/日月/雾/地面/颗粒），CSS 混合模式合成（白底 multiply 抠图、黑底 screen 雾、日月真 alpha）；5s 昼夜 Morph + 戏剧时钟；中英；KPI/路由粒子 mock；CDP 截图验收 6 张（1440×900、1920×1200）。
- **强项**：第一次让"昼夜=时间流逝"成立（问候语与时钟跟着走）；月亮被山脊真实遮挡的错觉做出来了；视觉最接近参考图。
- **弱项（即 V5 要解决的）**：本质是 2.5D 贴图堆叠——无真光影、无真纵深、阴影不会动；素材后处理成本高（见下）。
- **踩坑清单（V5 复用价值最高的一段）**：
  1. `position:fixed` 容器会创建 stacking context，**隔离 mix-blend-mode**：子元素的 multiply 只与容器内内容混合。夜里 sky 层淡出后 backdrop 变透明，白底素材原样发白。解法：昼夜渐变画在隔离容器自身上。
  2. 白底素材的"白"不是纯白（实测 236,239,241 且带 vignette），multiply 不再恒等 → 图层边界留矩形缝。解法：按角采样归一化 + ≥246 阈值截断。
  3. 黑底转真 alpha 要 unpremultiply（a=max(r,g,b)，rgb×255/a），否则光晕带黑环。
  4. 素材内容被图片边界硬切（雾顶、月光晕边缘）→ 元素级 mask 羽化。
  5. 过深的素材会吞掉叠在其上的深色 KPI 文字——素材色调要服从信息层可读性。
  6. Chrome 对无 Cache-Control 的 http 文档做启发式缓存，验收脚本必须带 `?v=N`。

## V5 方案（GPT 文本，23 节）

核心主张：Three.js 真实空间 + PBR 材质 + 昼夜时间轴 + 核显自适应；3D 场景与 DOM UI 严格两层；固定相机 + ±0.3° 视差；日月被山体真实遮挡；"夜景就是应该有黑"；Gate1-4 分阶段验收；性能三档 + 自动 benchmark + 动态 DPR。

## V4.1 实验（2026-09-09，Claude 调度大脑）——已归档

- **做了什么**：在 v4-实验的场景底（13 张分层 PNG + 5s morph）上补齐「真后台」——7 页 hash 路由 IA（总览/目录/路由/渠道/日志/分析/设置），数据层按线上 `api_page.html` 同口径移植（apiFetch/KPI/成员准入/限流/日志，15s 轮询 + 401 凭据 + 离线条），渠道身份用线上真实 brand logo；中英 + 问候/戏剧时钟 + auto/day/night 全保留。工程拆分 index.html + 5 css + 4 js，Playwright 验收 12 张（1440×900/1920×1200 昼夜、morph 2 中间帧、6 工作页）。
- **踩坑清单（v4-experiment 继承病 + 新增，V5 复用）**：
  7. **multiply 在无 mask 的 `<img>` 上会被 Chrome 丢弃**：arch 白底 PNG 夜里整块发灰（A/B 实锤原版夜景同样有此灰板，当时被误当天色接受）。修法：white-to-alpha 反演成真 alpha（近白像素 min≥200 → 全透明），彻底不依赖混合模式；工具在 `v4.1-experiment/tools/white_to_alpha.py`。
  8. **filter 过渡触发提升层快照**：morph 中途 arch 边界出现硬竖边（端点状态正常）。修法：夜间变暗改用 `opacity` 淡入，不过渡 filter。
  9. **全视口装饰 SVG 吞点击**：`.routes` 这类 inset:0 的装饰层必须 `pointer-events:none`。
  10. **数据未到时的选择器防御**：日志数组 selector 返回 `{}` 会让 `for…of` 抛错并炸掉整个 boot（现象：KPI/遥测全空、轮询不启动）。selector 一律返回数组。
- **留给后面**：夜版建筑/远山资产（提示词手册 M8/M3，本版用 alpha 转换顶住）；夜间 HUD 光晕在深脊上仍可再加一档；写操作目前仅总开关 PUT /api/switch。
