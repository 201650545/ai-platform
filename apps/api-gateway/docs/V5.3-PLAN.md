## 一、昼夜山雾系统

### 1.1 第一轮：用户出图贴图雾（已否决）

- 用户按我方提示词产出 5 片水墨雾（黑底、横向 3:1+、密度梯度：雾带 > 雾海 > 雾流 > 雾毯 > 雾纱）。
- `mist_prep3.py` 处理：黑场扣除→alpha=亮度→双色调（夜冷月白 206,220,240 / 昼暖白 243,240,233）→ 11 资产（5 夜 + band 翻转 + 5 昼）。
- 编排 6 夜层 + 3 昼层，各层正弦漂移 + fogNight 驱动。
- **用户否决**："像人吸了一口烟吐了一口气，很不自然"。根因：素材本质是"烟雾形状"——每片有丝缕、卷曲的明确轮廓，加上各自摆动，观感就是"一团烟在飘"。水墨山水的雾不是物体，是**留白**：谷底漫出的潮气把山的下半截吃掉，山尖浮在雾面上，无形状无边界。
- 结论：贴图路线治标不治本。11 张 `v53-mist-*` 资产留盘退役。

### 1.2 第二轮：GPU 噪声雾场（用户拍板"1试一试"，已落地）

- `src/fog.js`：独立透明 canvas（`#fog`）+ three.js ShaderMaterial，FBM 值噪声实时生成雾。
- 关键设计：
  - **海拔衰减**：密度谷底最浓、向上快速衰减，山尖以上无雾 → 雾"从谷底漫出来"；
  - 双层噪声域反向滚动（大团慢 + 细碎快），整片**涌动**而非烟团摆动；
  - 阈值 patchiness 让峰线穿插、山谷各有浓淡；
  - 水域上缘溶解带，雾在岸线处化开；
  - 55% 分辨率渲染上拉伸 = 免费羽化；screen 混合与水墨层天然相容；
  - DOM 位置：mid 山体之后、fg 之前 → 雾"吃"山脚。
- 驱动通道：
  - 夜：`uDensity = fogNight × .95`，色 月白 (0.796,0.859,0.937)；
  - 昼：`uDensity = (1-fogNight) × dayK × .85`，色 暖白 (0.953,0.941,0.914)；
  - `dayK` 真实时钟曲线：**清晨浓**（4.8-6.5h 升到 .95）→ **正午最少**（8.5-11h 落到 .16 底值）→ **傍晚中**（15.8-17.2h 回升 .6，18.2-19.6h 落回）。
- 连带退役：v4 老 `fog-day` 贴图雾（横带硬边、跟 toggle 不跟时钟，与新雾场职责重叠）。
- 验证（v52shot CDP）：hour=0/6.5/12/17.5 四时点截图，晨浓/午淡/暮中梯度成立；无烟丝、无矩形边界；fps 87-90；零页面报错。
- 状态：**待用户验收**。

## 二、日月分时系列（提示词已交付 2026-09-10，等用户出图）

出图计划：**共 2 张原图，拆 13 张素材**（太阳 5 态 + 月亮 8 相；每张横排，保证同套风格）；若拆图发现大小不齐，退路是同提示词逐个单独出。

### ① 太阳系列（1 张 5 态，横排）

```
水墨晕染风格的发光太阳图鉴，纯黑色背景。画面中水平排列五个同样大小的正圆太阳，间距均匀，从左到右代表一天中五个时刻：
1（清晨6点）：柔和的晨曦金橙，盘面偏软偏湿润，边缘带一圈淡粉橙的宽光晕，像刚升起的太阳；
2（上午9点）：明亮的暖金色，光质清透干净，光晕收敛；
3（正午12点）：最亮的香槟金近白，核心发白，光晕最紧最足；
4（下午3点）：饱和的金色，比正午略深略暖，光晕中等；
5（傍晚6点）：深沉的琥珀橙红，盘面明显变暗，光晕最大最散，带黄昏的朦胧暖雾感。
五个太阳只有亮度和颜色差异，形状都是正圆、大小完全一致；纯黑背景；不要山、不要水、不要云、不要月亮星星、不要任何文字。
```

### ② 月亮系列（1 张 8 相，横排，按一年中完整月相周期）

```
真实感月面图鉴，纯黑色背景。画面中水平排列八个月亮，间距均匀、本体大小完全一致，从左到右按月相周期排列，受光面遵循北半球规则（盈月亮右、亏月亮左）：
1（新月）：整轮极暗，只有盘缘一圈极淡的冷灰微光，几乎不可见；
2（蛾眉月）：一弯细亮弧在右侧，受光面淡金偏冷；
3（上弦月）：右半轮照亮，明暗界线清晰，银白色；
4（盈凸月）：右大半轮照亮，亮部银白带月海暗纹；
5（满月）：全轮照亮，最亮最清晰的银白，月面细节完整，带淡淡光晕；
6（亏凸月）：左大半轮照亮，色调偏清冷的蓝灰；
7（下弦月）：左半轮照亮，亮度略降；
8（残月）：一弯细弧在左侧，淡灰蓝，边缘朦胧。
八个月亮只有盈缺和明暗颜色差异，本体大小完全一致；纯黑背景；不要星星、不要云、不要山、不要水、不要任何文字。
```

### 接线设计（预告，出图后执行）

- 太阳：真实时钟取相邻两档**交叉淡化**（如 10 点 = 9 点盘 7 成 + 12 点盘 3 成），光感颜色随时间连续滑变。
- 月亮：按真实日期计算月相 → 取 8 相纹理档；新月那夜月亮近隐没。
- 太阳盘面缩小约两成（半径 .105 → .085 视高），出图后看效果微调。
- 蛾眉/残月走亮度抠形；凸月/满月仍走圆盘掩模（**月海必须保持不透明**，老规矩）。
