# V5.1 方案（对 GPT V5 的批评与修正）

> 2026-09-09。GPT 的 V5 构思（23 节）方向正确但不可直接执行；本文是辩证审查后的可实施版本。
> 开发位置：`apps/api-gateway/v5/`；进程记录：`V5-DEVLOG.md`。

## 〇、结局状态（2026-09-10 补记）

- **本方案已完整落地并验收**：Gate1（程序化白昼）/ Gate2（u Timeline）/ Gate3（DOM Dashboard + i18n）/ Gate4（六页降级 + 性能自适应）全过，快照存 `prototypes/v5.1-gates-passed/`，预览端口 3200（活线）与 3201（快照）。
- **但视觉方向被用户否决（09-09）**：全程序化零贴图观感不过关。按"V4 皮 + V5 骨"另建 `v5.2-experiment/`（V4 水墨资产复用 + V5.1 的 u 引擎/占位页/看门狗），现为 V5.3 实验线（GPU 噪声雾场 + 12h 弧线真实时钟天体），预览 3202。
- **结论**：5.1 的工程结论（零构建、单参数 u、Gate 制、DOM/3D 两层、降级策略）全部被 V5.2/V5.3 继承；5.1 的"全程序化资产"路线仅存档。演进全程见 `V5-DEVLOG.md`，后续规划见 `V5.3-PLAN.md`。

## 一、同意并保留的（V5 的对的部分）

1. **3D 场景 + DOM UI 严格两层**。UI 清晰度不被 3D 牺牲，文字永不烘焙进材质。
2. **固定相机 + 极小鼠标视差（±0.3°/±0.2°）**。有空间感，不像游戏。
3. **真实遮挡**：日月必须被山体真挡住——这是 V4 贴图堆叠做不到的。
4. **"夜景就是应该有黑"**。克制布光，不把所有东西照亮。
5. **昼夜 = Timeline，不是 Theme Transition**；UI 最后 0.7s 才适应（"世界先变化，系统随后适应"）。
6. **Gate 制验收**：Gate1 静止截图必须像建筑效果图，否则后面全免谈。
7. **性能从第一行代码设计**：失焦暂停、DPR 上限、动态降档。
8. **i18n 统一词条**，300ms fade 切换，不整页重渲染。

## 二、批评与修正（5.1 的差异）

### 1. GLB + PBR 纹理资产管线 = 最大风险，否决
V5 列了 5 个 GLB + 13 张 PBR 纹理（base/normal/rough ×4 套），但**没说谁产出、怎么验收**。V4 的教训：单张生成 PNG 都要水印裁切、白底归一化、unpremultiply 转 alpha 才能用；PBR 套装（三图一致性、无缝平铺）的生成与验收难度再高一个量级，且二进制资产不可 diff、不可复现。
**5.1：全程序化。** 山体 = PlaneGeometry + fBm 噪声位移（三层不同频率/振幅）；建筑 = 盒体组合（主墙+开口柱列+厚度）；地面 = 大平面 + canvas 噪声 roughnessMap；日月 = Sphere + Sprite 光晕；天空 = 渐变 Shader 球。**零二进制资产，代码即资产**，可进版本库、Obsidian 离线可开。

### 2. Vite + GSAP + TS 工具链，否决（原型期）
在 Obsidian 库内引入 node_modules 与构建步骤，与库卫生和用户的预览习惯（双击/静态服务器）冲突；外网常被掐，CDN 不可靠。
**5.1：零构建。** 原生 ES Modules + 本地 vendor 的 `three.module.js`；动画用约 80 行手写 rAF timeline（缓动+相位），不引 GSAP。

### 3. 六阶段秒级精度表，过早
保留**相位语义**（时间加速→长影→日落入山→蓝调→月升→UI 适应），但时长不锁死在方案里，按截图实测调。
**5.1 的结构改进：场景状态 = f(u) 单参数**，u∈[0,1] 为昼夜进度；切换=对 u 做 5.2s 缓动动画；截图验收可直接 setU(0.35) 取任意相位，可逆、可scrub、可测。

### 4. 1 秒 GPU benchmark 自动分档，过度工程
**5.1：单档默认**（DPR≤1.25、shadow 1024、失焦暂停）+ 持续低帧（<28fps 3s）自动降 DPR，恢复后回升。手动三档开关留给 Settings 后期。

### 5. 每页相机微移（第 10 节），scope creep
**5.1：其余六页只降场景曝光/权重，相机不动。**"同一个世界"的感觉靠降曝光拿到 80%，成本趋近零。

### 6. Provider 节点 3D 锚点 + CatmullRomCurve3，降级
路由线与节点继续走 **SVG/DOM 覆盖层**（V4 已验证、几乎零成本、文字天然清晰）；3D 与 UI 的边界保持干净。

### 7. 月亮定位，同意并落实
"介于月亮与 Gateway Core 之间"：程序化月面（弱噪声 bump、灰度差、无明显环形山）+ DOM 标签（GPT-4o / 核心），不烘焙。

## 三、5.1 范围与验收

- **Gate1 场景本体**：建筑/三层山/地面/太阳/相机/日光+真阴影。验收：白昼静止截图像建筑效果图。
- **Gate2 昼夜**：u 时间轴、月升、阴影真实移动、天空/雾/星渐变。验收：Day/Sunset/BlueHour/Night 四张截图都成立。
- **Gate3 Dashboard**：sidebar 七页、问候+戏剧时钟、KPI、providers、路由 SVG、中英、主题按钮；UI 在 u 的最后 0.15 适应。
- **Gate4 框**：其余六页=降曝光场景+工作台占位；性能自适应基础；1920×1200 验收。
- 验收工具：沿用 V4 的 CDP 无头截图管线（`previews/` 出图）。

- 核显 WebGL 不可用 → 检测后回退 V4 实验版静态合成（`prototypes/v4-experiment/` 保留即为退路）。
