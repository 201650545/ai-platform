# 主题设置 · 月夜穹顶 / Midnight Dome

> **以西式穹顶建筑为骨，以月夜光井为魂，以中央汇聚与多路分发为叙事核心的暗色控制台主题。**
> 适合夜间使用的暗色主题，融合**西式古典建筑、深夜穹顶空间、低照度高级材质、现代路由控制逻辑**，气质庄重、安静、精密、国际化。

## 一句话定义

**深夜中的一座穹顶中控大厅——所有请求从这里汇聚、被判断、再被分发到不同的成员渠道。**

## 核心气质

不是普通的“暗黑科技后台”，也不是赛博霓虹。追求的是：
- 夜色中的**秩序感**
- 建筑空间带来的**仪式感**
- 中央汇聚的**控制感**
- 低饱和深色中的**高级感**
- 兼具展示性与专业性的**国际化气质**

## 视觉世界观（对照三主题）

> 黑白建筑极简=“白天的理性建筑空间”；云海天舟=“东方山水中的流动调度”；星河枢机=“东方观星中的智能观测”；**月夜穹顶=“西式建筑中的夜间总控大厅”**。

重点不是“炫酷”，而是：**庄严、稳定、统一、受控**。

## 核心视觉隐喻

| 隐喻 | 含义 | 对应网关 |
|---|---|---|
| 穹顶 | 整个系统之上的总空间 / 统一秩序（全局视角、中央管理、结构完整、所有请求纳入同一体系） | 系统高层 |
| 圆厅中央中枢 | 统一 alias / 请求汇聚中心，请求进入→理解→路由 | alias / 汇聚中心 |
| 周边节点 | OpenAI、Azure、Anthropic、Google、Other Channels 等，是围绕中央圆厅的**侧厅、基座、分发端口**（比“圆点+线”更有空间感与建筑感） | 成员渠道 |
| 光束 / 地面放射纹 | 路由=从中央中枢发出的光束、地面石纹导流线、圆厅放射状路径 | 智能路由 |
| 请求在秩序之中被分发 | — | — |

## 与网关业务逻辑的对应

- **用户请求** → 进入中央中枢的光束 / 请求流
- **统一 alias** → 圆厅中枢的核心请求目标
- **多成员渠道** → 穹顶大厅四周的渠道节点 / 分发基座
- **智能路由** → 从中央向不同成员端发散的导流线
- **成员健康** → 各节点亮度、状态灯、刻度条
- **冷却机制** → 暂时变暗或降低活性的一侧节点
- **fault domain** → 不同节点分布在不同空间区段
- **rate limit** → 通道宽窄、配额条、阈值信息
- **route decision** → 最终被点亮的主线路径
- **telemetry** → 整个大厅对系统运行状态的持续观测

## 画面构图

明确的**“中央聚焦式构图”**（偏集中、对称或准对称、结构明确、适合“中央总控”）：
- 顶部：穹顶与月光
- 中央：圆厅与汇聚中枢
- 周边：分发成员节点
- 左侧：深色导航墙
- 右侧：监控、健康、准入序列

## 配色

不走高饱和科幻蓝紫。**暗，但不脏；贵，但不浮；亮点少而精。**

| 角色 | 色值 |
|---|---|
| 背景 | `#0F141A` / `#151B22` |
| 建筑暗面 | `#1B2129` |
| 石材灰 | `#3A4149` |
| 月光白 | `#D6D2C8` |
| 古铜金 | `#A9875A` |
| 微青冷光 | `#7D97A1` |

黑 / 深蓝灰=空间基底；月白=文字与月光高光；金色=强调路径、节点、选中态；极少量青绿=健康状态辅助。

## 材质语言

暗色石材、深色大理石、金属包边、微弱金属反光、夜间灯光、轻微玻璃/光井效果、抛光地面倒影。**必须克制**，不能变“豪华酒店风”。目标：**高等级基础设施的建筑感**，不是奢靡。

## UI 语言（长在建筑结构里，不浮在网页上）

- **左侧导航**：一面深色立墙，像穹顶大厅入口侧壁上的控制目录；文字与图标细、稳、直，不过度发光。
- **顶部 KPI**：像刻在穹顶下缘的一圈观测信息带 / 悬挂在上方的信息横梁；稳定数字 + 微弱折线 + 清晰标签 + 强烈秩序感（Throughput / Error Rate / Latency / Quota）。
- **右侧遥测**：嵌入墙面的观测面板（非漂浮玻璃窗），展示实时 telemetry、成员健康、最近路由决策、准入序列 01–05。
- **准入序列**：做成**仪式化序列面板**——01 HEALTH / 02 COOLDOWN / 03 FAULT DOMAIN / 04 RATE LIMIT / 05 ROUTE，像经过层层校验后才被放行的深夜中控流程。

## 字体与排版

- 西式经典感 × 现代产品感：英文标题略带古典气质或高对比优雅，正文与数字现代、清晰、可读，中文克制不花。
- 强调纵深与对称、留白适度；标题带“铭牌感”，数字与监控数据非常稳定。
- 关键词：**像建筑铭文，而不是普通后台文案。**

## 动效（若落地为网页）

慢、轻、克制：月光从穹顶缓慢投下；中央中枢轻微呼吸；路由路径在请求发生时短暂亮起；被选中的成员节点微微高亮；telemetry 曲线持续静默变化；admission sequence 在请求通过时逐段亮起。
不是“科技炫光”，而是：**深夜大厅中一套安静而精准的控制系统正在运行。**

## 正式主题定义文案

**月夜穹顶（Midnight Dome）**是一套面向夜间场景的 API 转发网关暗色主题。它以西式穹顶建筑为核心意象，将月夜光井、中央圆厅、中枢汇聚与多路分发结合在统一空间之中。整体采用深夜蓝黑、石墨灰、月光白与古铜金的低饱和高级配色，营造庄重、安静、精密、国际化的控制台气质。其设计强调中央总控、建筑秩序与仪式化流程表达，适合用于展示、讲解与夜间工作场景。
