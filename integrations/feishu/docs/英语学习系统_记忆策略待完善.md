## 二、项目简介

本项目是一个**个人英语学习的完整数据系统**，从飞书多维表格（Bitable）公开导出为静态 JSON，部署在 GitHub Pages，每小时自动同步一次。

### 核心数据链路

```
飞书多维表格（数据源）
   ↓ 公开导出（AI 公开导出 视图）
GitHub 仓库 → GitHub Pages（静态 JSON）
   ↓ 每小时同步
顶层 AI 读取数据 → 制定学习计划 → 学习 → 结果写回飞书 → 再次同步
```

### 关键特征

- **数据规模**：9 张数据表，共 7,647 条记录
- **同步层级**：hourly（每小时第 17 分钟同步）
- **核心使用者**：AI 代理，读取数据回答"今天该复习什么、最近学得怎么样"并制定当日计划
- **记录闭环**：所有学习行为（测验、翻译、会话）都写回飞书 → 同步 GitHub → 供顶层 AI 优化后续计划

## 三、当前学习方式说明

### 已采用的学习方式

学习者偏好**翻译有难度的文本**作为主学习方式。理由：翻译时主动回忆词义、主动构造句子意思，是"精加工记忆"，比孤立背词有效。

学习流程（当前已在对话中运行）：

```
选取真实外刊文本（如经济学人）→ 学习者翻译 → AI 批改
→ 点出误读词汇（附音标）→ 主动回忆测验 → 结果写回飞书
```

### 发现的问题（待解决）

1. **复习缺失**：学习者持续学新词，旧词（尤其 7 月学的"词频 201-300"批次，正确率仅 87%）未回炉，导致重遇时生疏。
2. **机械记忆缺位**：当前只有精加工（翻译），缺少快速的"词→义"机械记忆训练。
3. **工具联动断裂**：学习者原本使用独立 Anki 软件复习，但 Anki 无法与飞书联动，复习记录无法进入学习系统闭环。

## 四、待完善的核心问题：记忆策略与间隔重复复习设计

### 4.1 已确定的约束条件

- 复习必须**在对话内完成**（不引入独立 Anki 软件），保证结果写回飞书、进入系统闭环。
- 复习结果需标注"复习轮次"，便于下次接续调度。
- 需遵循**遗忘曲线 / 间隔重复**原理。
- 学习者不接受固定 A/B/C/D 四选一为主的形式（认为枯燥、区分度差）。

### 4.2 已提出的初步编排（消退提示 / Vanishing Cues）

同一个词，复习次数越多、选项越少，从"识别"走向"主动回忆"：

| 复习轮次 | 时间点 | 题型 | 目的 |
|---|---|---|---|
| 第1轮 | 当天 | 2选1 | 最低门槛，建立映像，不挫败 |
| 第2轮 | +1天 | 3选1 | 加难度，逼比较语义差异 |
| 第3轮 | +3天 | 4选1 | 干扰项更多，强化区分 |
| 第4轮 | +7天 | 不给选项·英翻中 | 关键转折，纯主动回忆 |
| 第5轮 | +15天 | 不给选项·中翻英 | 反向回忆，检验真掌握 |
| 第6轮 | +30天 | 语境运用（长句/翻译） | 进入长期记忆 |

### 4.3 编排规则（初步）

- 同一会话内不同词处于不同轮次，题型错开。
- 每个词按轮次推进，答错退回上一轮。
- 一轮复习 6-10 词，约 5-8 分钟。
- 每天节奏：先对话式复习（机械记忆）→ 再翻译精加工。
- 每轮结果写进飞书学习日志，标注复习轮次。

### 4.4 需要高级 AI 完善的点

1. **复习间隔的科学化**：1/3/7/15/30 天的间隔是否最优？是否应根据答对次数动态调整（类似 SM-2 / FSRS 算法）？
2. **题型与轮次的映射**：2选1→3选1→4选1→纯回忆的过渡节点是否合理？是否应增加"中翻英"在更早轮次出现？
3. **干扰项生成策略**：多选题的干扰项应如何选择（同义/反义/形近/词频相近），才能最有效？
4. **正确率阈值与回退机制**：答错退回上一轮是否合理？连续答错多次（如 3 次）是否应重启该词？
5. **记忆轮次次数的确定**：一个词需要多少次复习才能进入长期记忆？是否应区分词的难度等级（难词更多轮次）？
6. **学习日志字段设计**：为支持上述调度，飞书"学习日志"表需要增加哪些字段（如：当前轮次、下次复习时间、难度等级、连续答对/答错次数）？
7. **与现有数据表的整合**：如何与 vocabulary 表的"下次复习/记忆阶段/掌握状态"字段联动；能力状态表如何更新。
