# 教资备考系统 — 学习流程规范（P1）

## 1. 先测后学流程

### 流程步骤
1. **选择考点**：从考点信息表中选取待学习考点（学习状态="未学习"）
2. **前测出题**：Agent根据考点关联的题型模板，使用L4或L5级别模板生成测试题
3. **用户作答**：用户在不查看任何资料的情况下独立作答（is_看过资料=false）
4. **记录作答**：写入"学习作答记录"表，训练类型="前测"
5. **评分反馈**：Agent按评分要点评分，写入得分、评分结果、反馈内容
6. **判断基线**：根据前测结果确定考点初始掌握程度

### 作答记录必填字段
- 作答标题：`前测-{考点名称}`
- 关联考点：考点record_id
- 训练类型：前测
- 题目文本：Agent生成的题目
- 用户答案原文：用户作答内容
- 参考答案：标准答案
- 总分：题型默认满分值
- 得分：Agent评分
- 评分结果：完全正确/部分正确/错误
- 作答日期时间：提交时间
- 用时秒数：实际用时
- 是否看过资料：false
- 是否使用模板：true（前测允许使用L4-L5模板）
- 模板提示等级：L4或L5

## 2. 独立输出流程

### 流程步骤
1. **学习阶段**：用户学习考点知识内容
2. **独立作答**：不使用模板（模板提示等级=L0或L1），独立输出
3. **记录作答**：训练类型="独立练习"
4. **评分反馈**：Agent评分+反馈

### 关键区别
- 前测：允许L4-L5模板（了解题型框架）
- 独立练习：最多L1（仅告知题型名称）
- 模板撤除：连续正确2次降一级，直到L0

## 3. 反馈修订流程

### 流程步骤
1. **Agent反馈**：评分后生成反馈内容，指出：
   - 得分点/失分点
   - 错误模式分类（14种之一）
   - 改进建议
2. **用户修订**：根据反馈修改答案，写入"修改后答案"字段
3. **重新评分**：Agent对修改后答案重新评分
4. **对比分析**：原得分 vs 修改后得分，评估改进幅度

### 错误模式自动分类规则
| 错误大类 | 错误细类 | 判断标准 |
|---------|---------|---------|
| 概念记忆缺失 | 关键概念未提及 | 参考答案中核心概念在用户答案中缺失 |
| 概念边界混淆 | 相似概念混用 | 使用了不属于本题的相关概念 |
| 关键词遗漏 | 评分点未覆盖 | 评分要点中某些点完全未涉及 |
| 材料信息提取错误 | 材料内容误读 | 引用材料时出现事实性错误 |
| 答非所问 | 回答方向偏离 | 答案与题目要求不匹配 |
| 结构不完整 | 答题框架缺失 | 缺少开头/主体/结尾的某部分 |
| 理论与材料未结合 | 纯理论无材料 | 只写理论未结合题目材料 |
| 只写结论没有分析 | 缺乏推理过程 | 有结论但无分析推导 |
| 模板误用 | 模板不匹配 | 使用了不适合该题型的模板 |
| 表达不规范 | 语言不专业 | 口语化表达或术语使用错误 |
| 评分点遗漏 | 要点不全 | 部分评分点未涉及 |
| 审题错误 | 题意理解偏差 | 回答方向与题目要求不符 |
| 逻辑跳跃 | 推理链条断裂 | 论证过程缺少中间环节 |

## 4. 延迟复测流程

### 流程步骤
1. **错题入本**：评分结果="错误"的作答自动写入错题本
2. **设定复测日期**：根据错误模式设定复测间隔
   - 概念记忆缺失：3天后复测
   - 概念边界混淆：2天后复测
   - 关键词遗漏：3天后复测
   - 其他模式：5天后复测
3. **复测提醒**：到复测日期时通知用户
4. **复测执行**：使用相同考点生成新题目（不使用原题）
5. **复测结果记录**：写入错题本"复测结果"字段
   - 已掌握：错误次数归零，考点状态更新
   - 部分掌握：再延长3天复测
   - 仍未掌握：错误次数+1，标记为重点关注
6. **考点状态更新**：复测通过后更新考点信息表

## 5. 学习会话管理

### 会话生命周期
1. **创建会话**：开始学习时创建记录
   - 会话类型：前测/专项练习/综合练习/复习
   - 开始时间：当前时间
   - 会话状态：进行中
2. **会话中作答**：每条作答记录关联会话ID
3. **结束会话**：
   - 统计题目总数、正确/部分正确/错误/超时/放弃数
   - 计算得分率
   - Agent生成总结
   - 用户填写学习反思
   - 设定下次学习建议
   - 会话状态→已完成

### 会话统计自动更新规则
每次作答记录创建/更新时，自动更新关联会话的统计字段。
