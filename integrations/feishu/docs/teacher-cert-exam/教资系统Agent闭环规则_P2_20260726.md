# 教资备考系统 — Agent闭环读写规则（P2）

## 1. Agent角色定义

| Agent | 职责 | 读写权限 |
|-------|------|---------|
| QClaw | 出题、评分、反馈、错题归集、状态更新 | 全表读写 |
| 用户 | 作答、订正、反思 | 作答记录写、错题本写、会话写 |

## 2. 出题规则

### 出题流程
```
输入：考点record_id + 题型模板record_id + 模板提示等级
↓
读取考点信息表 → 获取考点名称、知识内容、知识树路径
读取题型模板表 → 获取对应等级的模板内容、评分要点、典型例题
读取真题库 → 搜索关联真题作为参考
↓
生成题目 → 写入"学习作答记录"表
  - 题目文本：生成的题目
  - 参考答案：标准答案
  - 关联考点：考点record_id
  - 关联题型模板：模板record_id
  - 训练类型：前测/独立练习/复习
  - 模板提示等级：L0-L5
  - 是否使用模板：根据等级判断
  - 总分：题型默认满分值
  - 作答状态：待作答
```

### 出题数量规则
- 前测：每个考点1道题
- 独立练习：每个考点1-2道题
- 复测：每个错题1道新题（不使用原题）
- 综合练习：跨考点2-3道题

## 3. 评分规则

### 评分流程
```
输入：作答记录record_id + 用户答案
↓
读取作答记录 → 获取参考答案、评分要点、总分
↓
评分维度：
  1. 内容覆盖度：参考答案中评分要点覆盖比例
  2. 结构完整性：答题框架是否完整
  3. 理论材料结合：是否结合题目材料
  4. 表达规范性：术语使用是否准确
  5. 逻辑连贯性：推理过程是否连贯
↓
计算得分 → 写入作答记录
  - 得分：数值
  - 评分结果：完全正确(≥90%)/部分正确(60-89%)/错误(<60%)
  - 反馈内容：具体反馈文本
  - 错误大类：14种之一
  - 错误细类：详细描述
  - 是否需要复测：错误→true
```

### 评分标准
| 评分结果 | 得分率 | 行动 |
|---------|--------|------|
| 完全正确 | ≥90% | 考点连续正确次数+1，考虑升级掌握程度 |
| 部分正确 | 60%-89% | 写入反馈，连续正确次数归零 |
| 错误 | <60% | 写入错题本，设定复测日期 |

## 4. 反馈生成规则

### 反馈内容结构
```
【得分情况】总分X分，得分Y分，得分率Z%
【评分要点覆盖】
  ✅ 已覆盖：要点1、要点2
  ❌ 未覆盖：要点3、要点4
【错误模式】概念记忆缺失
【改进建议】需要重点记忆XX概念的定义和核心特征
【修改建议】在第二段中补充XX理论的具体应用
```

### 反馈语气
- 鼓励性：先肯定正确部分
- 具体性：指出具体缺失内容
- 可操作性：给出明确修改方向

## 5. 错题归集规则

### 自动写入错题本的条件
- 作答记录评分结果 = "错误"
- 或得分率 < 60%

### 写入字段映射
| 错题本字段 | 来源 |
|-----------|------|
| 错误模式分类 | 作答记录.错误大类 |
| 错误原因分析 | 作答记录.反馈内容 |
| 错误次数 | 同一考点累计错误次数 |
| 复测日期 | 当前日期 + 复测间隔 |
| 复测结果 | "未复测" |
| 是否已订正 | false |
| 关联作答记录 | 作答记录record_id |

## 6. 考点状态更新规则

### 作答后自动更新
```
读取作答记录的评分结果
↓
更新考点信息表：
  - 总作答次数 +1
  - 如果正确：总正确次数 +1，连续正确次数 +1
  - 如果错误：连续正确次数 = 0，最近错误模式 = 错误大类
  - 最近检测日期 = 作答日期
  - 最近检测结果 = 评分结果
  - 最近7天作答数 重新计算
  - 学习状态：未学习→学习中（首次作答后）
  - 掌握程度：
    * 连续正确≥3次 → 已掌握
    * 连续正确≥1次 → 基本掌握
    * 连续正确=0且有错误 → 未掌握
  - 下次复习日期 = 根据掌握程度计算
    * 已掌握：7天后
    * 基本掌握：3天后
    * 未掌握：1天后
```

### 掌握程度升级规则
| 当前程度 | 连续正确次数 | 升级到 |
|---------|------------|--------|
| 未学习 | 1 | 基本掌握 |
| 未掌握 | 1 | 基本掌握 |
| 基本掌握 | 3 | 已掌握 |
| 已掌握 | 5 | 熟练掌握 |

## 7. 模板撤除规则

### 撤除触发条件
- 撤除策略 = "正确两次降一级"（默认）
- 每次作答评分结果 = "完全正确" → 当前等级降一级
- 作答评分结果 ≠ "完全正确" → 保持当前等级

### 撤除路径
```
L5完整模板 → L4简化模板 → L3关键词提示 → L2仅结构标题 → L1仅题型名称 → L0无模板提示
```

### 撤除记录
每次作答记录中的"模板提示等级"字段记录本次使用的等级，用于追踪撤除进度。
