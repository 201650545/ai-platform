# 教资备考系统 — 自动化规则（P3）

## 1. 定时任务清单

### 1.1 每日复习提醒
- **触发时间**：每天 08:00（Asia/Shanghai）
- **执行逻辑**：
  1. 查询考点信息表，筛选"下次复习日期" ≤ 今天的记录
  2. 查询错题本，筛选"复测日期" ≤ 今天的记录
  3. 汇总生成当日待复习清单
  4. 发送复习提醒消息
- **消息模板**：
  ```
  📚 今日复习清单（{date}）
  ├── 考点复习：{count1}个
  │   ├── {考点1}（{掌握程度}，已{n}天未复习）
  │   └── {考点2}（...）
  ├── 错题复测：{count2}个
  │   ├── {错题1}（错误模式：{模式}，第{n}次复测）
  │   └── {错题2}（...）
  └── 预计用时：{minutes}分钟
  ```

### 1.2 每周学习统计
- **触发时间**：每周日 20:00（Asia/Shanghai）
- **执行逻辑**：
  1. 统计本周作答记录：总数、正确率、各训练类型分布
  2. 统计本周新学考点数、掌握程度变化
  3. 统计本周错题数、复测通过率
  4. 生成周报写入学习会话表的Agent总结
  5. 发送周报消息

### 1.3 弱项分析报告
- **触发时间**：每周三 18:00（Asia/Shanghai）
- **执行逻辑**：
  1. 按错误模式分类统计本月错误分布
  2. 识别高频错误模式（top 3）
  3. 找出关联的薄弱考点
  4. 生成针对性练习建议
  5. 发送弱项分析消息

### 1.4 学习进度检查
- **触发时间**：每天 21:00（Asia/Shanghai）
- **执行逻辑**：
  1. 检查今日是否有作答记录
  2. 如果没有，发送温和提醒
  3. 如果有，统计今日学习时长和完成度

## 2. 仪表盘配置

### 2.1 总览仪表盘
- **卡片1**：学习进度总览
  - 总考点数 / 已学 / 学习中 / 未学习
  - 掌握程度分布饼图
- **卡片2**：近期作答趋势
  - 最近30天每日作答数折线图
  - 正确率趋势线
- **卡片3**：错误模式分布
  - 按错误大类统计的柱状图
  - 高频错误模式标红

### 2.2 考点掌握仪表盘
- **卡片1**：按知识模块分组的掌握度热力图
- **卡片2**：待复习考点列表（按下次复习日期排序）
- **卡片3**：连续正确次数排行榜

### 2.3 学习会话仪表盘
- **卡片1**：每日学习时长柱状图
- **卡片2**：会话类型分布
- **卡片3**：得分率趋势

## 3. 自动化触发规则

### 3.1 作答记录创建后触发
```
事件：学习作答记录表 新增记录
↓
1. 更新关联考点信息表
   - 总作答次数 +1
   - 总正确次数（如果正确）
   - 连续正确次数
   - 最近检测日期/结果
   - 最近错误模式
   - 掌握程度
   - 下次复习日期
2. 如果评分结果="错误"
   - 自动写入错题本
   - 设定复测日期
3. 更新关联学习会话
   - 题目总数 +1
   - 对应结果数 +1
   - 重新计算得分率
```

### 3.2 错题复测通过后触发
```
事件：错题本 复测结果 变为 "已掌握"
↓
1. 更新关联考点信息表
   - 连续正确次数 +1
   - 重新评估掌握程度
2. 更新关联作答记录
   - 是否需要复测 = false
3. 错题本记录标记完成
```

### 3.3 学习会话结束后触发
```
事件：学习会话表 会话状态 变为 "已完成"
↓
1. 计算最终统计数据
   - 题目总数
   - 正确数/部分正确数/错误数/超时数/放弃数
   - 得分率
   - 总用时分钟
2. Agent生成学习总结
3. 根据得分率生成下次学习建议
   - ≥80%：建议学习新考点
   - 60%-79%：建议复习薄弱考点
   - <60%：建议重新学习当前模块
```
