# AI 自助资源运营体系（ai-resource-hub）

> 一句话定位：**把永涛拥有的数字资源（API/账号/免费权益/工具/网关）统一收集、分类、授权给本地 AI，让 AI 以本人身份自主调用，而不是由人手动分配。**

**这个体系不是给人看的，是给 AI 看的。** 人只做两件事：提供规则与钥匙、在 AI 判定需要人工时介入。

---

## 为什么做这个

- 各家 AI（DeepSeek / Kimi / 豆包 / 千问 / Grok / 生图站…）能力各不相同，资源散落在各处，每次用都要人去找、去填、去配。
- Cherry Studio 已解决「网关聚合」的痛点，但**让 Claude Code 用特定模型仍要人工反复配置**。
- 目标：本地 AI 读到飞书多维表格，**自动**搜寻可用资源并直接用起来——等于它自己就有「钱包」和「工具箱」。

## 核心哲学

1. **AI 自主分配，不是用户分配** —— 用户把资源和使用方法、密钥都备好，AI 拿去自取。
2. **架构用最先进模型把关，内容用性价比模型执行** —— 结构错一点全盘重来，必须最先进模型审；文字/批量/填充量大且便宜，性价比模型跑。
3. **长期监控（飞书）+ 即时监控（本地调度器）分层** —— 飞书是长期认识，每次调用额度的即时累计在调度器本地。
4. **GitHub 作为数据桥** —— 数据导到 GitHub Pages 公开 JSON，ChatGPT/Anthropic 官网连接器直接读，省最先进模型的 API 钱。
