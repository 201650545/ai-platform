【背景】
我有一个「多 Agent 共享记忆」系统：多个 AI Agent 协作完成**多个不同项目**（例如：Agent A 做记忆系统项目、Agent B 做课件生成、Agent C 做英语教学），共享同一个 GitHub 仓库作为唯一记忆真源。当前机制：STATE.md（全局当前快照，保留式更新 + 稳定 S-ID，S-ID 格式为 S-YYYYMMDD-NN **无项目前缀**）、DECISIONS.md（用户决策，append-only + D-ID）、CHANGELOG.md（操作流水，append-only）。写入靠 git pull --ff-only → 重读 STATE → 改文件 → commit → push，有 pre-commit hook 守卫（凭证扫描 + S-ID 消失检测 + size guard + archive 锁 + STALE）。
