## 错误分类落地

quota_exhausted→EXHAUSTED / 429→COOLDOWN / 401→CRED_INVALID / model_not_found→CONFIG_INVALID / 5xx→可切同能力实例；200 包错误也识别（不重放）。流式已输出后禁切换。

## 已知偏差

1. `route_priority` 为 SQLite 运行态字段，seed INSERT OR IGNORE 只首次写入——改配置 priority 需清 DB 或手工 UPDATE（M2 对齐飞书配置真源做同步）
2. 流式为整读再透传，长流式有缓冲；M3 改逐块转发
3. 请求级互斥锁，M1 吞吐有限；并发路由预留留 M2
4. openai-compatible 真实上游未接实际凭证（key 空占位），M3 接飞书表2/表4 后启用
