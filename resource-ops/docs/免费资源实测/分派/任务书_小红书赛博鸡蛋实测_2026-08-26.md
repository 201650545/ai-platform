## 二、平台一：B.AI

### 基本信息
- 平台入口（网页聊天）：`http://chat.b.ai/chat`
- 平台官网/API 控制台：`https://b.ai`（登录后进入 API Dashboard）
- 限免模型（4 个）：
  1. `DeepSeek-V4-Flash`（文本）
  2. `DeepSeek-V4-Flash-Vision-Exp`（视觉，需上传图片测试）
  3. `HY3`（文本）
  4. `MiMo V2.5`（文本）
- 结束时间：未知；可能存在频率限制，需实测确认。

### 测试步骤
1. **注册/登录**：打开 `http://chat.b.ai/chat`，注册账号（邮箱+密码+验证）并登录。若已有账号直接登录。
2. **网页聊天测试**：
   - 在模型菜单中依次切换到上述 4 个模型；
   - 每个模型发送统一测试提示词，记录是否成功返回、返回内容、是否报错、是否有频率限制提示；
   - 视觉模型额外上传一张测试图片（可用任意公开图片 URL 或本地图片），询问「请描述这张图片的内容」。
3. **API 测试**：
   - 进入 API Dashboard；
   - 选择 **Official Mode + Full Access**；
   - 生成 API Key；
   - 用该 Key 调用 `DeepSeek-V4-Flash` 发一条测试请求，确认 API 可通、是否计费/免费、响应是否正常。
4. **记录**：按下方「记录格式」填写。

### 注意事项
- 若网页聊天有频率限制，记录触发条件（如「连续 N 次后提示」）；
- 若 API 需要绑定支付方式才能用，明确记录（这会影响「免费」判定）。

## 三、平台二：GMI Cloud

### 基本信息
- 平台入口：`https://www.gmicloud.ai`（登录后进入 Console）
- 活动名称：**MiniMax Week**
- 活动时间：**2026-08-24 至 2026-09-06（共 14 天）**
- 限免模型（4 个）：
  1. `MiniMax M3`（文本/编码/Agent）
  2. `MiniMax M2.7`（文本）
  3. `MiniMax Speech 2.8`（语音合成）
  4. `MiniMax Music 3.0`（音乐生成）
- 已知限制（需实测确认）：
  - 有用户反馈存在 **20 亿 token 总量限制**；
  - 可能存在 **速率限制（如 20 RPM）**。
- **重要：MiniMax H3 不在免费名单，仍按请求计费，不要测 H3。**

### 测试步骤
1. **注册/登录**：打开 `https://www.gmicloud.ai`，注册并登录。若已有账号直接登录。
2. **确认免费额度**：进入 Console，查看活动页/模型列表，确认 4 个免费模型是否可见、是否标注 Free/免费，记录新用户是否有赠送额度（如优惠码兑换）。
3. **文本模型测试**：
   - 分别用 `MiniMax M3`、`MiniMax M2.7` 发送统一测试提示词，记录响应与是否计费。
4. **语音模型测试**：用 `MiniMax Speech 2.8` 生成一段中文语音（文本建议：`你好，这是一段来自 MiniMax Speech 2.8 的测试语音。`），记录是否成功、输出格式、是否计费。
5. **音乐模型测试**：用 `MiniMax Music 3.0` 生成一段短音乐（提示词建议：`一段轻快的钢琴曲，约 15 秒`），记录是否成功、输出格式、是否计费。
6. **记录**：按下方「记录格式」填写。

### 注意事项
- 若活动页需要领取/兑换才能免费，记录领取路径；
- 若触发速率限制或 token 上限，记录具体现象。
