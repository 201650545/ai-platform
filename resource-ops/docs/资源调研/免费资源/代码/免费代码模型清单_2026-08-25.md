## 六、汇总

### 按类别统计

### 关键发现

1. **海外平台**：OpenRouter 免 tiers 最明确（50 次/天，25+ 免费模型）；Google Gemini 免费 tier 按 RPM/RPD 限制；DeepSeek 无永久免费档（仅新用户 5 元赠送）；Groq 免费 tier 速度快但额度待确认。
2. **国内平台**：智谱 GLM-4-Flash 永久免费、魔搭每日 2000 次调用、硅基流动 9B 以下模型永久免费、讯飞星火每月 500 万 token 是最明确的免费档；火山方舟和 CodeGeeX 免费规则待确认。
3. **编程 Agent**：Cursor 和 Windsurf 免费档具体额度待确认（官方页面 JS 渲染无法直接获取）；Qwen Code 与百炼共享免费额度。
4. **代码解释/审查**：多数平台复用其 API 免费额度，无独立免费档。
