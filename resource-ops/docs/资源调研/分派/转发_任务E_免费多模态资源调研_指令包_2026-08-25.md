## 0. 总则

### 0.1 目标
对国内外免费多模态 AI 资源做一次系统性调研，三件事：
1. **核实**：已有 54 个平台（见 §1）的免费规则、每日免费额度、有效期、领取方式是否准确、有无变化
2. **补充**：发现表中未收录的免费多模态 AI 资源（新增条目）
3. **输出**：结构化调研结果（§4 格式），可直接回填飞书多维表格「多模态生成资源库」

### 0.2 调研边界（最高优先，违反即作废）
- **不充值、不付费、不绑卡、不订阅套餐、不开启后付费**
- 只调研**免费额度 / 免费档**；付费内容仅作备注
- **严禁编造**：所有额度、规则、有效期必须来自官方页面 / 官方文档 / 实测；无法确认的标注「未确认」，不得猜测
- 每条信息标注**来源**（官网URL / 官方文档 / 实测 / 第三方），第三方信息需标注「第三方口径」

### 0.3 调研分类

| AI生图 | 文生图 / 图生图 / 绘画平台 | 即梦AI、LiblibAI、Leonardo |

## 2. 每条资源的调研字段

与飞书「多模态生成资源库」表字段一致，逐条填写：

| 字段 | 类型 | 说明 |
|------|------|------|
| 工具名称 | text | 平台/工具名称 |
| 类别 | 多选 | AI生图 / AI视频生成 / AI 3D生成 / 多模态API |
| 地区 | 单选 | 大陆 / 海外 |

| 能力 | text | 支持的能力（如「文生视频、图生视频、文生图」） |
| 官网链接 | url | 官方入口 |
| 免费规则 | text | 免费政策描述（含口径来源） |
| 每日免费额度 | text | 具体数值（如「66灵感值/日」） |
| 有效期 | text | 额度有效期 / 清零规则 |
| 领取方式 | text | 自动到账 / 手动签到 / 控制台领取 |
| 备注 | text | 实测结果、注意事项、口径差异 |

> 可选测试字段（执行 AI 有账号且能实测时填写，否则留空）：登录成功 / 额度到账 / 扣减正确 / 生成成功 / 总体结论（值：通过 / 失败 / 未测）

## 3. 调研步骤

### 3.1 官方信息核实（每个平台必做）
1. 打开官网 / 官方文档 / 定价页
2. 记录：免费规则、每日额度、有效期、领取方式
3. 记录来源 URL 作为证据

### 3.2 第三方交叉验证
- 搜索第三方评测 / 教程 / 社区讨论，交叉验证免费规则
- 官方与第三方不一致时，两者都记录并标注口径

### 3.3 免费额度实测（可选，有账号时）
- 登录账号，确认额度是否到账
- 实际生成一次，确认扣减是否正确
- 记录实测结果（成功/失败、扣减数值、水印情况）

### 3.4 新资源发现
- 调研过程中发现的、表中未收录的免费多模态 AI 资源
- 按 §2 字段完整填写，单独列入「新增资源表」
