## 2. 表1 账号资产汇总（21 条）

字段：`account_id`(唯一键) / `平台名称` / `账号标识` / `认证方式`(select) / `会话状态`(select) / `绑定手机`(checkbox) / `浏览器Profile` / `上次会话验证` / `下次会话验证` / `人工介入原因` / `状态`(select) / `备注`

**填写规则：**
- `account_id`：`acc-<平台拼音>-1`，如 `acc-siliconflow-1`（用 §1 的平台名小写转拼音/英文）
- `认证方式`：百度=微信扫码；腾讯混元/TokenHub=微信扫码；MiniMax/讯飞/阶跃=手机短信；其余按登录方式总览（Google OAuth/密码/手机短信）
- `会话状态`：已登录→`LOGGED_IN`；需人工→`NEEDS_HUMAN`；退役→`EXPIRED`
- `状态`：在用/停用（退役的用`停用`，未登录的用`待绑定`）
- `人工介入原因`：NEEDS_HUMAN 或待办项填写，其余留空
- `绑定手机`：智谱=未处理(false)；其余已知的按登录方式（有手机绑定的=true，未知=false）
- `备注`：免费额度一句话 + 待办要点

## 4. 表3 资源能力规格表（21 条）

字段：`capability_id`(唯一键) / `资源名称` / `类别`(select) / `逻辑模型` / `质量等级`(select) / `调用方式`(select) / `adapter_id` / `协议版本` / `认证方案`(select) / `允许主机` / `模型族` / `endpoint` / `请求体模板` / `健康探测` / `路由组` / `免费额度描述` / `请求模板版本` / `状态`(select)

**填写规则：**
- `capability_id`：`cap-<平台英文>`，如 `cap-siliconflow`（与表1 account_id 对应）
- `类别`：LLM API（绝大多数）/ 云GPU（Colab）
- `逻辑模型`：该平台主推免费模型，如 siliconflow→`Qwen/Qwen3-Omni-30B-A3B-Captioner`、deepseek→`deepseek-chat`（DeepSeek-V3 兼容）、zhipu→`glm-4-flash`、openrouter→`:free` 聚合、groq→`llama-3.3-70b-versatile`
- `质量等级`：T0（旗舰 GLM-5.2/DeepSeek-V4-Pro/Kimi-K3）/ T1（标准）/ T2（免费档/轻量）
- `调用方式`：`HTTP_REST`（有 API 的平台）/ `OPENCLI_BROWSER`（Colab 交互式）
- `认证方案`：`bearer`（有 key 的）/ `none`（Colab）
- `允许主机`：endpoint 的 host，如 `api.siliconflow.cn`
- `请求体模板`：OpenAI 兼容模板 `{"model":"{{MODEL}}","messages":[{"role":"user","content":"{{PROMPT}}"}]}`（不含 Secret）
- `路由组`：默认 = capability_id（唯一真源在此）
- `状态`：可用（有 key 且免费可用）/ 待验证（key 未确认）/ 失效（RETIRED）
- `免费额度描述`：一句话，如「每日 200 万 token 永久免费档」
