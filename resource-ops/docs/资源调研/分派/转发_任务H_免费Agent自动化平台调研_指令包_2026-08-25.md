## 0. 总则

### 0.1 目标
调研国内外免费 Agent / 自动化平台，三件事：
1. **发现**：各平台免费 Agent 框架 / 浏览器自动化 / 定时调度 / 工作流自动化能力及免费额度
2. **核实**：免费规则、每日免费额度、有效期、领取方式是否准确
3. **输出**：结构化调研结果（§4 格式），可直接回填飞书「多模态生成资源库」

### 0.2 调研边界（最高优先，违反即作废）
- **不充值、不付费、不绑卡、不订阅套餐、不开启后付费**
- 只调研**免费额度 / 免费档**；付费内容仅作备注
- **严禁编造**：所有额度、规则、有效期必须来自官方页面 / 官方文档 / 实测；无法确认的标注「未确认」
- 每条信息标注**来源**（官网URL / 官方文档 / 实测 / 第三方）

### 0.3 调研分类
| 类别 | 说明 | 示例 |
|------|------|------|
| Agent框架 | 可自主执行任务的 Agent 平台 | n8n、Dify、Coze、HuggingFace Agents |
| 浏览器自动化 | 浏览器操作/爬取自动化 | Playwright、Puppeteer、Browserless |
| 定时任务/调度 | 定时触发、CI调度 | GitHub Actions、Cloudflare Cron |
| 工作流自动化 | 无代码工作流编排 | Zapier、Make、飞书自动化 |

地区：**大陆** / **海外**

## 3. 调研步骤

### 3.1 官方信息核实（每个平台必做）
1. 打开官网 / 官方文档 / 定价页
2. 记录：免费规则、每日额度、有效期、领取方式
3. 记录来源 URL 作为证据

### 3.2 第三方交叉验证
- 搜索第三方评测 / 教程 / 社区讨论，交叉验证免费规则
- 官方与第三方不一致时，两者都记录并标注口径

### 3.3 免费额度实测（可选，有账号时）
- 登录账号，确认额度是否到账
- 实际运行一次（触发一个工作流 / 跑一次自动化），确认扣减是否正确
- 记录实测结果（成功/失败、扣减数值、稳定性）

### 3.4 新资源发现
- 调研过程中发现的、表中未列出的免费 Agent/自动化资源，按 §2 字段完整填写
