2. 每平台按交接书 §六 格式记录：
   ```
   ## 平台 N · 平台名 ✅/❌
   - 平台：URL
   - 登录态：✅/❌（判断依据）
   - 登录方式：Google OAuth / 手机短信 / 微信扫码 / 账号密码
   ```
