## 0. 总则（两个任务共享）

### 0.1 目标
逐平台验证登录态 + 摸清免费额度现状，为资源库第一张「可执行规格表」提供素材。
结果统一追加到：`docs/资源调研/验证记录_2026-08-10.md`（沿用现有格式，平台编号接着 10 续写）。

### 0.2 执行环境
用 **opencli** 控制已打开的日常 Chrome（永涛登录态）：
- `opencli browser n8hh7hyn open <url>` — 打开页面
- `opencli browser n8hh7hyn state` — 看页面交互元素（找登录按钮/账号菜单）
- `opencli browser n8hh7hyn extract` — 提取页面 markdown（判断登录态用 PowerShell 过滤：`Select-String -Pattern "Sign in|Profile|Settings"`）
- `opencli browser n8hh7hyn eval "<js>"` — 执行页面 JS（处理按钮点击等）

### 0.3 三条指令（永涛拍板，必须遵守）
1. **能谷歌登录的平台 → 自动点谷歌登录**（Google OAuth，点后确认是否登录成功）
2. **需要手机号 / 微信扫码登录 → 不自动操作**，记录到「待永涛登录清单」（平台名 + 登录方式）
3. **有账号密码登录的平台 → 备注提示永涛**设置账号密码（避免短信验证收费）

### 0.4 每平台记录格式（写回验证记录）
```
## 平台 N · 平台名 ✅/❌
- 平台：URL
- 登录态：✅/❌（判断依据）
- 登录方式：Google OAuth / 手机短信 / 微信扫码 / 账号密码
- 免费额度现状：具体额度/余额/代金券
- 价值：对资源库有什么用
- 待办：需要人做什么
```

### 0.5 完成后汇报（四段式，写在验证记录末尾或单独汇报）
1. **模块 × 验收项**：探测了哪些平台、每平台是否完成验证
2. **变更清单**：验证记录新增/改了什么
3. **验证**：哪些平台已登录、哪些待永涛登录
4. **已知偏差**：没跑通的平台、猜测、待确认点

- **A3 Together.ai**：谷歌登录 → API key 页 → 免费层额度（每月免费 requests / 免费模型）
- **A4 Mistral**：谷歌登录 → 免费额度（实验免费层 Open-Mistral 政策，可能已改为需绑卡）
