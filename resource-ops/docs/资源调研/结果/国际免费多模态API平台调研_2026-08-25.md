# 国际免费多模态 AI API 平台调研报告

> 调研时间：2026-08-25 · 方式：WebSearch + WebFetch 官方文档/定价页
> 重点：生图 / 3D / 视频 三类多模态能力 + 中国用户可访问性

---

## 一、OpenRouter

- 官网：https://openrouter.ai/
- **免费额度**：3 类免费模型均 20 RPM；<10 credits 时 50 次免费请求/天；≥10 credits 时 1000 次/天
- **刷新机制**：按日重置 · **需绑卡**：否 · **OpenAI 兼容**：✅
- **生图**：❌（官方明确免费池没有 `:free` 生图模型，生图需走 credit balance）
- **3D/视频**：免费 tier 不聚焦

**结论**：适合文本/多模型路由，**不适合做生图免费网关**。

## 二、Google AI Studio / Gemini API

- 官网：https://aistudio.google.com/ · API 文档：https://ai.google.dev/gemini-api/docs
- **免费额度**：免费 tier（Gemini 2.5 Pro 5 RPM/100 RPD；Flash 10 RPM/250 RPD；Flash-Lite 15 RPM/1000 RPD）
- **刷新机制**：按日重置 · **需绑卡**：否 · **OpenAI 兼容**：否
- **生图**：有限（免费 tier 含 basic image generation）
- **视频**：❌（Veo 3.1 在免费方案中不可用）
- **3D**：否
- **中国访问**：需特殊网络 + Google 账号

## 三、Stability AI ⭐（生图+3D）

- 官网：https://platform.stability.ai/ · API 文档：https://platform.stability.ai/docs
- **免费额度**：注册 25 free credits（1 credit = $0.01）
- **刷新机制**：一次性 · **需绑卡**：否 · **OpenAI 兼容**：否
- **生图**：✅（Stable Image Ultra/SD3.5 等，0.9 credits 起）
- **3D**：✅（Stable Fast 3D 10 credits、Stable Point Aware 3D 4 credits）
- **视频**：官方定价页未展示视频 API

## 四、fal.ai ⭐（视频）

- 官网：https://fal.ai/ · API 文档：https://fal.ai/docs
- **免费额度**：注册 $20 trial credits；**Grok Imagine 视频每日 5 次免费**（24h 滚动窗口）
- **刷新机制**：trial 用完即止；Grok 按日 · **需绑卡**：否 · **OpenAI 兼容**：否
- **生图**：✅（FLUX 等）· **视频**：✅（Grok Imagine Video 1.5，image-to-video，带原生音频）
- **3D**：未确认

## 五、Replicate

- 官网：https://replicate.com/
- **免费额度**：部分公开模型 limited free runs
- **刷新机制**：有限 runs，用完需加 billing · **需绑卡**：免费 tier 否 · **OpenAI 兼容**：否
- **生图**：✅（Flux 等，flux-1.1-pro 约 $0.04/image）· **视频**：✅（支持视频工具）

## 六、Together AI

- 官网：https://www.together.ai/ · 文档：https://docs.together.ai/
- **免费额度**：资料不一致（$5/$1 credit）；官方要求最低 $5 credit 余额
- **OpenAI 兼容**：✅
- **生图**：✅（Image models Free tier 60 Img/min）

## 七、Cloudflare Workers AI ⭐（生图，每日刷新）

- 官网：https://developers.cloudflare.com/workers-ai/
- **免费额度**：**10,000 Neurons/day**（flux-1-schnell 约 43 neurons/张 → 约 230 张/天）
- **刷新机制**：每日 00:00 UTC 重置 · **需绑卡**：否 · **OpenAI 兼容**：否
- **生图**：✅

## 八、Hugging Face Inference API

- 官网：https://huggingface.co/
- **免费额度**：第三方称 30,000 API calls/月
- **刷新机制**：按月 · **需绑卡**：否 · **OpenAI 兼容**：否
- **生图**：✅（依赖 Hub 开放模型，免费 tier 不保证所有模型稳定）

## 九、Groq

- 官网：https://groq.com/
- **免费额度**：第三方称 30 RPM / 14,400 requests/day
- **生图/3D/视频**：否（主要 LLM/TTS/ASR）

## 十、Pollinations.ai（生图）

- 官网：https://pollinations.ai/ · API：https://pollinations-ai.com/api
- **免费额度**：匿名 tier 约 15 秒/次（有水印）
- **生图**：✅（text-to-image、image-to-image）

## 十一、Nano Banana（生图）

- 官网：https://officialnanobanana.com/ · API：https://docs.nananobanana.com/api
- **免费额度**：注册 5 free credits（默认模型 1 积分/次）
- **生图**：✅（7 个模型、4K 无水印）

## 十二、Leonardo.ai（生图）

- 官网：https://leonardo.ai/
- **免费额度**：150 tokens/day（约 18-30 张/天）
- **刷新机制**：每日重置 · **生图**：✅

## 十三、Ideogram.ai（生图）

- 官网：https://ideogram.ai/
- **免费额度**：10 slow credits/week（约 10-40 张，默认公开）
- **刷新机制**：每周 · **生图**：✅

## 十四、Runway ML（视频）

- 官网：https://runway.com/pricing
- **免费额度**：125 credits 一次性（约 25 秒 Gen-4 Turbo 视频，有水印）
- **视频**：✅

## 十五、Pika Labs（视频）

- 官网：https://pikaslabs.com/
- **免费额度**：150 credits/month（约 10-30 个视频）
- **刷新机制**：每月 · **视频**：✅（Pika 2.5）

## 十六、Luma AI / Dream Machine（视频）

- 官网：https://lumalabs.ai/
- **免费额度**：第三方称 80-250 credits/day（有水印）
- **刷新机制**：每日 · **视频**：✅

## 十七、Kling AI（视频，中国友好）

- 官网：https://kling.kuaishou.com/
- **免费额度**：第三方称约 2000 credits/month（约 66 credits/day，有水印）
- **刷新机制**：每日 · **视频**：✅ · **中国访问**：快手出品，中国开发者更友好
