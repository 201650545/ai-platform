# 国内免费多模态 AI API 平台调研报告

> 调研时间：2026-08-25 · 方式：WebSearch + WebFetch 官方文档/定价页
> 口径：区分「新人免费体验包」（一次性/有有效期）与「免费模型」（长期免费，有速率限制）
> 重点：生图 / 3D / 视频 三类多模态能力

---

## 1. 阿里云百炼（Model Studio / 通义万相）

- 控制台：https://bailian.console.aliyun.com
- 免费额度文档：https://help.aliyun.com/zh/model-studio/new-free-quota
- API：`https://dashscope.aliyuncs.com/compatible-mode/v1`（OpenAI 兼容）

| 类型 | 额度 | 有效期 | 备注 |
|---|---:|---|---|
| 新人免费额度 | 多数模型 100 万 Token/模型 | 90 天 | 仅华北2（北京）地域；主账号与 RAM 子账号共享 |
| 图像生成 | 部分模型 100/200/500 张 | 90 天 | 以控制台模型详情页为准 |
| 视频生成 | HappyHorse 等检索到 10 秒免费体验 | 90 天 | 以控制台为准 |
| 3D 生成 | 未确认 | - | 未检索到免费额度信息 |

**关键规则**：免费额度仅抵扣实时推理；额度过期不补发；新用户无需实名即可获取免费额度；**wanx 等多模态生成模型不支持通过文本 Base URL 直接调用**，需通过百炼应用的 Skill/扩展机制接入。

## 2. 智谱 AI BigModel（CogView / CogVideoX）

- 控制台：https://open.bigmodel.cn
- API：`https://open.bigmodel.cn/api/paas/v4`（OpenAI 兼容）
- 定价页：https://open.bigmodel.cn/pricing

| 类型 | 额度 | 有效期 |
|---|---:|---|
| 新用户赠送 | 2500 万 Token（2000 万入门 + 500 万企业） | 3 个月 |
| 免费模型 | GLM-4-Flash、GLM-4V-Flash、**CogView-3-Flash（生图）**、**CogVideoX-Flash（视频）** | 长期免费，有速率/并发限制 |

**关键规则**：手机号即可注册，免信用卡，国内直连。免费模型是长期免费，非一次性赠送。

## 汇总对比表

| 平台 | 生图 | 3D | 视频 | 免费额度 | 刷新机制 | OpenAI 兼容 |
|---|---|---|---|---|---|---|
| 阿里云百炼 | ✅ 100/200/500张 | ❓ | ✅ 10秒体验 | 100万Token/模型 | 90天一次性 | ✅ |
| 智谱 BigModel | ✅ CogView-3-Flash | ❓ | ✅ CogVideoX-Flash | 2500万Token | 赠送3个月/免费模型长期 | ✅ |
| **腾讯云 TokenHub** | ✅ 50次 | ✅ 100积分 | ✅ 50积分 | 多类 | 1年一次性 | ❓ |
| 百度千帆 | ❓ 500张(第三方) | ❓ | ❓ | ERNIE-Speed-8K永久 | 永久/3个月 | ❓ |
| 讯飞星火 | ✅ 支持 | ❓ | ❓ | 500万Token/月 | 每月刷新 | ❓ |
| 硅基流动 | ✅ 50GB流量 | ❓ | ❓ | 14元+9B以下永久 | 一次性/永久 | ✅ |
| **魔搭 ModelScope** | ✅ 2000次/天 | ❓ | ❓ | 2000次/天 | **每日重置** | ✅ |
| 阶跃星辰 | ✅ 限时免费 | ❓ | ❓ | 30天体验 | 一次性 | ❓ |
| MiniMax/海螺 | ❓ | ❓ | ✅ 10次/日 | 3000积分 | 每日重置 | ❓ |

**关键发现**：
1. **腾讯云 TokenHub** 对生图/视频/3D 三类能力免费额度最明确（50次/50积分/100积分，1年）
2. **智谱** 免费模型覆盖生图和视频（CogView-3-Flash、CogVideoX-Flash）
3. **魔搭 ModelScope** 每日 2000 次调用，每日重置，适合做高频低额场景
4. **阿里云百炼** 生成类 API 接入方式特殊，不能直接走文本 Base URL
5. 3D 免费 API 明确度低，仅腾讯 TokenHub 明确提供
