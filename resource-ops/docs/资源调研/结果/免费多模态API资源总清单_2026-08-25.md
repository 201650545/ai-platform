### 网关路由原则
- **按能力路由**：生图→Seedream/CogView/HY-Image；3D→Seed3D/HY-3D；视频→Seedance/HY-Video/fal
- **额度轮换**：同一能力多平台，额度用尽自动切换下一家
- **每日刷新优先**：优先使用「每日刷新」类额度（火山协作奖励、魔搭、Cloudflare、fal）
- **OpenAI 兼容优先**：火山、智谱、硅基流动、魔搭、OpenRouter、Together 可直接统一接入
