# 免费多模态 API 转发网关方案（v1.0）

> 版本：v1.0（2026-08-25）
> 目标：把火山方舟 + 国内外免费多模态 API 聚合成一个统一网关，按能力路由、按额度轮换，最大化利用每日刷新的免费额度
> 上游资源池：`docs/资源调研/结果/免费多模态API资源总清单_2026-08-25.md`

---

## 一、设计目标

1. **统一入口**：一个 OpenAI 兼容的 base_url，内部按能力（生图/3D/视频/语言）路由到不同上游
2. **额度轮换**：同一能力多平台，免费额度用尽自动切换下一家，不中断
3. **每日刷新优先**：优先消耗「每日刷新」类额度（火山协作奖励、魔搭、Cloudflare、fal），避免浪费
4. **密钥安全**：API Key 只存本地，不进配置平面、不上云
5. **可观测**：记录每次调用的平台/额度消耗，形成使用报表

## 三、核心模块

### 3.1 能力路由（modality router）

| 请求端点 | 能力 | 上游优先级（额度用尽自动降级） |
|---|---|---|
| `/v1/images/generations` | 生图 | 火山Seedream → 智谱CogView → 腾讯HY-Image → 魔搭 → Cloudflare |
| `/v1/3d` | 3D生成 | 火山Seed3D → 火山Hitem3D → 火山Hyper3D → 腾讯HY-3D → Stability |
| `/v1/videos` | 视频生成 | 火山Seedance → 腾讯HY-Video → fal Grok → 海螺 → Kling |
| `/v1/chat/completions` | 语言 | 火山DeepSeek/GLM → 智谱 → 硅基流动 → 魔搭 → OpenRouter |
| `/v1/embeddings` | 向量 | 火山Doubao-embedding-vision |

### 3.2 额度管理（quota manager）

- **额度登记表**：每个上游实例记录 `剩余额度 / 刷新周期 / 下次刷新时间`
- **到点停止**：额度耗尽自动标记不可用，路由到下一家
- **每日刷新**：定时任务（每日 00:05）重置「每日刷新」类额度状态
- **冷却机制**：调用失败（限流/鉴权）自动冷却该上游 N 分钟

### 3.3 密钥库（vault）

- 本地 JSON 加密存储（如 `credentials.json`，值不出设备）
- 网关只引用密钥 ID，不暴露明文
- 与 `方案书.md` 的凭证库设计一致

### 3.4 使用报表（stats）

- 记录：时间 / 能力 / 上游平台 / 模型 / 消耗额度 / 成功失败
- 输出：按平台、按能力的额度使用统计，识别「哪家免费额度最划算」

## 四、上游适配层（adapter 接口）

每个平台一个 adapter，统一接口：

```python
class UpstreamAdapter:
    name: str          # 平台名
    modality: list     # 支持能力: [image, video, 3d, chat, embedding]
    quota: QuotaInfo   # 剩余额度/刷新周期
    def generate_image(self, prompt, **kw): ...
    def generate_video(self, prompt, **kw): ...
    def generate_3d(self, prompt, **kw): ...
    def chat(self, messages, **kw): ...
    def embed(self, text): ...
```

**第一批 adapter（OpenAI 兼容，可直接复用统一 client）**：
- 火山方舟：`https://ark.cn-beijing.volces.com/api/v3` ✅ 已开通
- 魔搭 ModelScope：OpenAI 兼容 ✅
- 智谱 BigModel：`https://open.bigmodel.cn/api/paas/v4` ✅
- 硅基流动：`https://api.siliconflow.cn/v1` ✅
- OpenRouter：OpenAI 兼容 ✅

**第二批 adapter（自有 API 格式）**：
- 腾讯 TokenHub、Cloudflare Workers AI、fal.ai、Stability AI、海螺、Kling

## 六、风险与注意

| 风险 | 应对 |
|---|---|
| 免费额度政策随时调整 | 以各平台控制台为准，额度登记表定期核对 |
| 生成类 API 格式不统一 | 每个平台独立 adapter，统一网关出口 |
| 阿里云百炼生成类不能走文本 Base URL | 如需接入，走百炼 Skill/扩展机制，单独 adapter |
| 国际平台访问不稳定 | 火山/国内平台为主力，国际平台作补充 |
| 3D/视频免费额度少 | 火山 3D 额度最充足（265万 tokens），优先消耗 |
