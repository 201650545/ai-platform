## 4. 分配决策规则（Claude 自主，用户已授权）

1. **先查库再分配**：任务需要能力 → 读能力规格表找 `状态=可用` + 质量等级满足 → 读实例表找该能力可用实例。
2. **免费/低价优先**：实例按 `路由优先级` 升序（1 免费 → 高优先消耗）；已 `quarantined`（如 cap-aliyun-01）一律不选。
3. **不换模型、不降质**：轮换只发生在同一 `routing_group`/`capability_id` 内（同逻辑模型）；跨模型/跨质量等级禁止切换。
4. **额度到点停**：实例 `剩余额度`/`额度到期日` 到安全余量 → 标 EXHAUSTED 不再选，报告缺口（回到周期1 收集/领取）。
5. **优先走已编排网关**：日常 LLM 调用优先 `:3100` 已编排统一模型组（符合「只用 :3100 编排组」规矩）；编排外先问。
6. **测试用免费模型**：验证/测试一律用 `:3100` 免费模型（deepseek-free / qwen3.8-flash / @cf/ 系列），不用 DeepSeek 官方 / 付费模型。
7. **桌面 AI 当执行器**：需要图形/桌面操作任务 → `opencli trae-solo open-task/send`（模型锁定 DeepSeek V4 Flash 正式版）。
